## Scalar survivor-background interface

The exact finite background signature uses grid pair counts and occupancies on 23
side-four or 83 side-five canonical response lines. Perfect-matching row/column gauge
reduces selector dimensions to 32 and 99. All response occurrences use only 39 affine

The new residual form removes every pair contribution forced by tracked response lines:

\[
u_B(q)=p_B(q)-\sum_{L\ni q}\binom{h_B(L)}2\ge0.
\]

For every response,

\[
N_B(Q)=
\sum_{q\in Q}u_B(q)+
\sum_L\left[
\binom{h_B(L)+r_Q(L)}3-\binom{h_B(L)}3

These are necessary realizability inequalities and an exact score identity. They are
not a complete description of all geometrically realizable signatures.

## Linked operation and destroyed threshold

A composed certificate binds canonical fibre identity, source witness data, survivor
background, literal operation geometry and the exact full selector. For every response,

\[
\Delta\Psi(Q)=N_B(Q)-T,
\]

where `T` is the certified number of destroyed current triples. Thus the full selector
is strictly improving exactly when `N_B^*<T`. The declared parent response carries an
exact policy penalty, which is distinct from deletion credit, rollback distance,
uniform slack and labelled routing slack.

## Labelled response frontier

Every accepted geometric assignment bundle now yields one exact nonnegative child
vector `v(Q)` for every response. Its coordinate sum is the exported all-ones score.
Duplicate vectors are kept as an exact quotient class. Responses dominated
componentwise by another vector cannot minimize any strictly positive child weighting;
every positive-weight minimizer is therefore Pareto-minimal.

This does not assign unlabelled destruction credit to child states. A real SCC proof
still needs explicit child weights, routed credits and strict recurrent inequalities.

## Canonical real-fibre batch interface

One batch entry composes the linked operation certificate, residual background
certificate and labelled Pareto certificate over the same source. Records are ordered
by unique `fibre_id`; all aggregate counts are reconstructed.

Completeness is recognized only relative to an explicit expected fibre-ID registry. If
no registry is supplied, the batch is marked incomplete regardless of its size. The
built-in 120-operation suite validates this interface using synthetic accepted sources;
it does not populate the genuine parent-rule fibres.

## Corrections retained

- Canonical IDs, signatures, residuals, affine chambers and Pareto vectors are not semantic quotients.
- Fibre linkage proves identity, not transition or state semantics.
- Necessary signature inequalities are not a realizability characterization.
- Equal scalar selectors do not imply equal labelled offspring vectors.
- A positive-weight minimizer is Pareto-minimal, but not every Pareto vector is claimed exposed.
- Batch completeness requires the explicit expected fibre-ID registry.
- Rollback changes the operation; it is not deletion credit in the original row.
- Occurrence correction, rollback, selector penalty, policy penalty and uniform slack are distinct.
- Literal strictness requires the actual destroyed threshold and survivor relation.
- Passing finite checkers proves only their stated equalities.

## Bottom line

There is no complete proof. Through **CMR2093**, the finite response layer includes
necessary residual realizability constraints, exact labelled Pareto pruning and a
canonical batch format for genuine operations. Completion still requires the expected
fibre registry, full real population, legal operation and fate semantics, strict
recurrent labelled certificates and the global integer CRT quotient.
