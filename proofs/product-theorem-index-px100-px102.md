# Product theorem index addendum: PX100--PX102

The main product theorem index advanced concurrently through PX99. This addendum
records the next available identifiers.

| ID | Statement | Status | Location |
|---|---|---|---|
| PX100 | Every side-`n` factor has a factor-compatible rectangle state with simultaneous bounds `D_2<=48n` and `D_3<=221184 n H_(2n-1)` | PROVED | `docs/60-exact-sparse-rectangle-reservoir.md` |
| PX101 | A rank-two/rank-three defect hypergraph has an independent set of size at least `nq-e_2q^2-e_3q^3` | PROVED | `docs/60-exact-sparse-rectangle-reservoir.md` |
| PX102 | Every side-`n` factor has an exact no-three reservoir of `Omega(n/sqrt(log n))` whole product rectangles | PROVED | `docs/60-exact-sparse-rectangle-reservoir.md` |

PX102 is an exact all-side partial product theorem. It does not yet cover every
row and column, so it is not an infinite multiplicative-closure theorem.
