## Logical gain

Zero-neighbourhood objects are no longer anonymous uncovered records. For every object and historical recognizer kind, the compiler separates:

1. rows already present;
2. missing rows available with a sound physical certificate;
3. physically unavailable rows;
4. rows conflicting with the retained object.

Only the second case is a construction task. If at least one recognizer is feasible, the least weighted completion bundle is canonical. A finite batch is solved by an exact minimum prerequisite-closed completion atlas. If none is feasible, the object carries one exact rigid row witness.

A typed shortage is similarly reduced to finite producer reachability. It either has a canonical shortest live-source path or a residual producer cut proving it permanent in the current source dictionary.

Every permanent boundary route now requires a complete certificate: terminal predicate, producer cut, conservation excess, positive phase-cycle drift, or funded reset. Nonpositive drift and unfunded reset are not accepted as progress.
