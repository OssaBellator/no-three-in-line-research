# Alternating-Core Proof Chain

**Branch:** `research/alternating-core-chain`

This is the principal dependent proof-chain branch. It starts after the proved alternating star-neutralization bank and develops second-order concentration, paid structural re-extraction, no-recycling, two-colour termination, reverse-scale compatibility, and the prime-minus-one endpoint. Canonical proof notes are stored in `docs/`.

> **Status:** The bounded-denominator exit has exact ordinary and reflected scalar adapters. Lower one-sided fronts are finite states with `h<=q`; mixed collisions have one coprime/divisibility normal form; actual clean partners are support-faithful executable BDA products. Missing BDA partner cells have canonical active completion, blocker repair through occupancy four, and install-then-decode products. Companion records have actual paid rectangle decoders, bare installation is not charged, and the fibre quadratic excludes all internal midpoint triples. AC3fa--AC3fd now give every executable failed bank an exact created-cell-rank split `N1+N2+N3`, improving clean and missing-support returns to `1/96` or `1/192`, absent-companion returns to `U/(153K)`, and coherent multiscale returns to `W/(186K)` before optional finer labels. The rational-inverse fixed, quadratic-channel, and crossed-blocker outputs now carry exact pre-transition current/new words: closure count equals created-cell rank; moving triples use seven nonzero words; blocker complexes use eleven crossed-count/word states. These objects are collateral of the already paid bank, so no invalid payment is assigned at classification time. The remaining work is termination of rank-one current-pair contexts, rank-two secants, rank-three all-new tuples, finite AC2d overload labels, affine chains and global no-recycling. The branch still lacks a total transition oracle.
