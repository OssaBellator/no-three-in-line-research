# Ranked capacity-source networks and cyclic-core reduction

**Branch:** `research/alternating-core-chain`

AC3qk--AC3qo close physical-capacity activation and recreation when every gross
positive capacity increment is paid directly from one finite nonreplenishing source
ledger.  The next source layer allows a capacity source to create lower-ranked capacity
sources before those lower sources create physical capacity.  This note lifts the
acyclic replenishment machinery AC3po--AC3pt to that setting.

The terminal quantity is gross physical capacity creation, not live source-unit
creation.  Two reverse weights are useful: terminal-yield weights bound all gross
capacity creation, while strict path-product weights bound the number of accepted
network transitions.  Cycles reduce to the already classified conservative-cycle or
multi-output SCC residual.

## Ranked capacity-source network

Let `A_cap` be a finite set of exact capacity-source types and let `beta` be the
terminal physical-capacity sink.  Fix a directed acyclic graph on

`A_cap union {beta}`

with `beta` a sink.  An edge `a->v` has integer rate

`rho_(a,v)>=0`.

Source type `a` has an integer counter `s_a>=0`.  Total physical capacity is `B>=0`.
For one transition declare gross source debits `d_a>=0`, gross source creations
`r_a>=0`, gross physical-capacity creation `G>=0`, and gross physical-capacity
destruction `D>=0`, with

`s_a'=s_a-d_a+r_a`,

`B'=B-D+G`.

Debit and creation are recorded separately even when both occur at one source type.
The transition is **capacity-network-faithful** when

`r_v <= sum_(a:a->v) rho_(a,v)*d_a`

for every `v in A_cap`, and

`G <= sum_(a:a->beta) rho_(a,beta)*d_a`.

Every created source or capacity unit must therefore have a registered predecessor
debit.  Source addresses include every rate, physical target role and payment-relevant
decoration.

## AC3qp -- terminal-yield weights bound gross capacity creation -- PROVED

Set `y_beta=1`.  In reverse topological order define

`y_a=sum_(v in A_cap:a->v) rho_(a,v)*y_v + rho_(a,beta)`.

Equivalently, `y_a` is the sum of rate products over all directed paths from `a` to
`beta`.  It is a nonnegative integer and may be zero when `a` has no path to the
terminal sink.

Define the residual terminal-yield stock

`Y=sum_(a in A_cap)y_a*s_a`.

Every capacity-network-faithful transition satisfies

`Y'-Y <= -G`.

Consequently, along every finite history,

`sum_t G_t <= Y(0)=sum_a y_a*s_a(0)`.

### Proof

The source update and creation bounds give

`Y'-Y=sum_v y_v*r_v-sum_a y_a*d_a`

`<=sum_a d_a*sum_(v in A_cap:a->v)rho_(a,v)y_v-sum_a y_a*d_a`

`=-sum_a rho_(a,beta)d_a <= -G`.

Sum and telescope.  The final yield stock is nonnegative. QED.

This is a gross-creation bound.  Destroying and recreating one physical capacity unit
still spends terminal yield again.

## AC3qq -- strict ranked-capacity potential -- PROVED

Set `w_beta=1` and define in reverse topological order

`w_a=1+sum_(v in A_cap:a->v)rho_(a,v)w_v+rho_(a,beta)`.

Put

`Psi_cap=B+sum_a w_a*s_a`.

Every capacity-network-faithful transition satisfies

`Psi_cap'-Psi_cap <= -D-sum_a d_a`.

Hence any accepted transition with

`D+sum_a d_a>=1`

strictly decreases `Psi_cap` by at least one.

### Proof

Using the update equations,

`Delta Psi_cap=-D+G+sum_v w_v*r_v-sum_a w_a*d_a`.

The terminal and source creation bounds imply

`G+sum_v w_v*r_v`

`<=sum_a d_a*(rho_(a,beta)+sum_v rho_(a,v)w_v)`

`=sum_a d_a*(w_a-1)`.

Substitute to obtain the displayed inequality. QED.

The additional `1` in `w_a` pays for the debit event itself; the terminal-yield weight
`y_a` omits it because AC3qp measures only physical capacity creation.

## AC3qr -- exact ranked-capacity transition bound -- PROVED

Inside one fixed acyclic capacity-source epoch, assume every accepted network
transition has `D+sum_a d_a>=1`.  Then

`# accepted transitions <= Psi_cap(0)`

and

`sum_t D_t+sum_(t,a)d_(t,a) <= Psi_cap(0)`.

### Proof

Sum AC3qq over the history.  The final potential is nonnegative and each accepted
transition decreases it by at least its declared gross destruction plus source debit.
QED.

## AC3qs -- combined amplification and ranked capacity recreation -- PROVED

Consider one maximal physically feasible alpha-pure source-unit segment as in AC3qm.
Let

`A_amp=sum_t(h_t-1)_+`,

`L_amp=sum_t(1-h_t)_+`,

and let `D_cap=sum_t D_t` be gross physical-capacity destruction on that segment.
Suppose every gross positive physical-capacity increment is generated by the fixed
acyclic capacity-source network above.  Then

`A_amp+D_cap`

`<=L_amp+(B(0)-S(0))+sum_a y_a*s_a(0)`.

### Proof

AC3qm gives

`A_amp+D_cap <= L_amp+(B(0)-S(0))+sum_t G_t`.

Apply AC3qp to the segment's capacity-source history. QED.

Thus lower-ranked source creation cannot hide unbounded physical headroom.  The entire
recursive contribution is already present in the finite initial terminal-yield stock.

## AC3qt -- ranked/cyclic capacity-source router -- PROVED

For an arbitrary finite capacity-source dependency graph, contract its strongly
connected components.  The condensation graph is acyclic, so AC3qp--AC3qs close all
inter-component capacity creation once each cyclic component has an internal route.

Fix one positive cyclic component `S`.  For `a in S`, count **all** declared output slots
of a debit at `a`: internal slots returning to `S`, slots leaving to lower condensation
components, and terminal physical-capacity slots to `beta`.  Strong connectivity gives
at least one internal slot at every source.  Exactly one of the following holds:

1. every source has exactly one total output slot; then that slot is internal, has rate
   one, there are no exits from `S`, and `S` is one conservative directed unit cycle;
2. one canonical source has at least two total output slots, possibly because an internal
   unit-cycle edge is accompanied by an exit or terminal-capacity slot;
3. a change of rates, addresses, terminal roles or payment semantics is an outer reset.

The first case closes when phase is quotient-stuttering or finitely ticketed.  The second
case is the canonical realized multi-output capacity-source residual.

Consequently ranked or acyclic capacity-source recreation is no longer open.  A unit
internal cycle with any positive outgoing or terminal edge is correctly routed to the
multi-output case rather than misclassified as conservative circulation.

### Proof

The condensation statement is AC3ps applied with `beta` as the terminal capacity sink.
Inside `S`, strong connectivity supplies at least one positive internal output slot at
each source.  If every source has one total slot, there can be no external or terminal
slot; the internal positive graph is therefore the all-unit functional SCC of AC3pw and
is one directed simple cycle.  Otherwise the least source with at least two total slots
and its first two ordered slots give the AC3py address.  AC3px closes the conservative
case under its quotient/ticket contract. QED.

## Corrected AC4 source frontier

Fixed physical source capacities, one-level source-paid capacity recreation and every
finite acyclic hierarchy of capacity sources now close.  Remaining source-growth cases
are:

- fresh physical atoms outside every fixed candidate universe;
- phase-sensitive unticketed circulation inside a capacity-source SCC;
- realized multi-output amplification inside a cyclic capacity-source SCC;
- shared or nonadditive capacity not represented by exact additive coordinates;
- outputs without occurrence-faithful atom addresses;
- unpaid source loss or payment-relevant unticketed conservative circulation.

The other AC4 interfaces remain genuinely unbounded structural semantics, nonfactoring
continuations, recreatable non-source tickets, unresolved availability/conflict/reverse
gates, nonadditive owners and scalar/arithmetic macro cycles.
