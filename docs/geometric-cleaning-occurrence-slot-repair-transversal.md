# Geometric-cleaning occurrence-slot repair transversal

## Contract

Fix one finite cause-use graph `G=(U,S,E)` over faithful donor, remedy, height and physical-source slots. Every incidence retains cause, donor, source, remedy, height, conditioning and lineage fields. Let `C` be the canonical least maximum-deficit cleaning core from GC2kz--GC2ld and put

`delta = |C| - |N_G(C)| > 0`.

A repair extension `G+=(U,S+,E+)` contains the old graph and admits an injective cleaning assignment `P:U -> S+`. New slots and edges retain complete geometric lineage.

## Theorem block GC2le--GC2li

### GC2le — missing-neighbour repair count

For

`R_P(C) = {(u,P(u)) : u in C and P(u) notin N_G(C)}`,

one has `|R_P(C)| >= delta`. At most `|N_G(C)|` core causes can use old neighbouring slots, while all `|C|` causes receive distinct slots.

### GC2lf — genuinely new cleaning incidence

Every pair in `R_P(C)` belongs to `E+ \ E`. It is therefore a new donor/remedy/height compatibility or a newly supplied faithful slot, not an old incidence under a new name.

### GC2lg — canonical cleaning repair transversal

The first `delta` pairs in complete geometric address order form a canonical transversal with distinct cause uses and distinct outside slots.

### GC2lh — cause/class concentration

If repair incidences have `L` exact donor, remedy, height or source-creation classes, one class carries at least `ceil(delta/L)` transversal pairs. All cause and lineage fields remain explicit.

### GC2li — failure and resets

Fewer than `delta` distinct outside compatible slots cannot repair the core. Omitted geometry, hidden issuance, splitting, relabelling, reuse, untagged feedback or changed conditioning returns the first exact reset witness.

## Consequence

Every successful cleaning repair supplies `delta` distinct faithful donor/remedy/height incidences outside the old core neighbourhood. Construct them, pay them from named source deposits, or prove them geometrically impossible.

This theorem is conditional on the complete cleaning use/slot and repair-extension contracts. It does not prove GC5 or the no-three-in-line conjecture.
