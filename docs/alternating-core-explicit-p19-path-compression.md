# Exact compression of the explicit p=19 terminal path

## Status

This note keeps AC as the only active track and proves AC5nh--AC5nj. It shortens the explicit `p=19`, `n=18` switch certificate without changing its installed initial state or terminal no-three-in-line configuration.

The statements are certificate-specific. They do not prove that the compressed path is globally shortest in the full two-permutation switch graph.

## Symmetry group

Let `G` be the order-sixteen group generated by the eight square symmetries and interchange of the red and blue permutation layers. Every element of `G` preserves disjoint permutation pairs, legal two-row switches and the real collinear-triple potential.

## AC5nh -- exact state and symmetry audit -- PROVED

The raw post-installation certificate contains 390 state occurrences joined by 389 switches.

Exactly one state is repeated: the states at raw indices 257 and 259 agree. Hence the path contains exactly 389 distinct physical states.

No two distinct physical states in the certificate lie in the same `G`-orbit. Therefore the certificate contains exactly

\[
\boxed{389}
\]

square-symmetry/layer-swap orbits. In particular, the two-step exact loop is the only compression obtainable by identifying path states up to board symmetry and layer interchange.

### Proof

Canonicalize every state by taking the lexicographically least image under the sixteen group actions. The 389 distinct states have 389 distinct canonical representatives. Direct state comparison finds the sole repeated occurrence at indices 257 and 259. QED.

## Recorded-state graph

Let `V_rec` be the 389 distinct states occurring in the certificate. Join two vertices when one legal two-row switch changes one state into the other, whether or not that edge was used consecutively in the original path. Call the resulting finite graph `G_rec`.

## AC5ni -- exact shortest route inside the recorded-state graph -- PROVED

Breadth-first search in `G_rec` gives

\[
\boxed{
\operatorname{dist}_{G_{\rm rec}}(v_{41},v_0)=357.
}
\]

Thus the recorded state set contains a terminal certificate using 357 switches, saving

\[
\boxed{389-357=32}
\]

switches from the raw route.

The shortest route uses fifteen shortcut edges. Fourteen shortcuts bypass two intermediate state occurrences and one shortcut bypasses four. Every shortcut is itself one legal two-row switch and is retained with its exact layer and row pair in `data/ac-p19-path-compression.json`.

### Proof

Enumerate every legal two-row neighbour of every vertex in `V_rec` and retain exactly those neighbours also lying in `V_rec`. Ordinary breadth-first search from the installed 41-triple state returns distance 357. Its predecessor path is replayed edge by edge, and all fifteen nonconsecutive edges are checked directly against the two permutation layers. QED.

## AC5nj -- compressed terminal manifest -- PROVED

The 357-switch route starts at the same alternating-star installed state, never exceeds potential 41, and terminates at the same zero-triple state.

Including the initial alternating-star installation, the compressed explicit manifest therefore contains

\[
\boxed{358}
\]

physical operations.

No route using only states already present in the raw certificate can use fewer than 357 switches. This is an exact finite optimality statement for `G_rec`, not for the complete switch graph.

### Proof

The breadth-first predecessor path proves both the upper bound and shortest-path lower bound inside `G_rec`. Recomputing every state potential gives maximum 41 and terminal value zero. Adding the initial installation gives 358 operations. QED.
