# Terminal pencils from bounded marked hosts re-enter closed classes

PP3aqh--PP3aqn give a zero-cost second trade unless the complete ordinary-helper
support hypergraph has a near-linear fixed-core pencil.  The support hypergraph was
built from the same finite canonical source and insertion classes as
PP3aod--PP3aoj.  Fixing several distinguished local indices does not create a new
class; it only moves some endpoint indices from the variable support into the
bounded core.

The terminal pencil therefore re-enters the already closed source or insertion
geometries.  Source pencils yield credited endpoint banks or are impossible by
unique completion.  Insertion pencils are `A_2`, `B_3`, or `B_4` and are absorbed
or cancelled by PP3aoy--PP3aqn.

Thus failure of the bounded-multimarked independent set is not a recursive new
frontier.  Only an external source/pool/Hall/alternating host failure can prevent
the closed conversion chain.

## 1. Type preservation under bounded conditioning

Fix a bounded distinguished endpoint set `D` and a fixed ordinary-helper core

```text
F subseteq H,
|F|<=4.
```

Suppose a terminal pencil consists of positive canonical signatures

```text
G_x, x in X,
```

whose complete endpoint supports have the form

```text
D_G union F union {x},
```

with `D_G subseteq D` fixed and `x` variable.

### Proposition PP3aqo -- PROVED

All signatures in the pencil belong to one common canonical class after passing
to a subfamily of constant relative size.  That class is one of:

1. unary source;
2. anchored transition/source pair;
3. anchored pair of endpoint rank four;
4. inserted source triple of rank four, five, or six;
5. rank-two unary insertion `A_2`;
6. rank-three binary insertion `B_3`;
7. rank-four binary insertion `B_4`.

No additional class is created by conditioning on `D union F`.

#### Proof

The canonical normal form contains finitely many source and insertion types,
orientations, and endpoint roles.  Pigeonhole those finite choices.  Conditioning
fixes endpoint indices and selected arcs but does not change the defining number
of inserted cells, retained anchors, or candidate incidences.  Therefore the
retained family has one of the listed original types. ∎

The variable index may occupy any one of finitely many endpoint roles; fix that
role by another constant pigeonhole.

## 2. Source-class pencils

### Theorem PP3aqp -- PROVED / CONDITIONAL EXISTING ENDPOINT-HOST INTERFACES

A near-linear terminal pencil of a source class has one of the following outcomes.

1. A unary or transition pencil yields a target-size source star, transition
   sunflower, or credited endpoint bank through PP3aan--PP3aau and
   PP3acv--PP3adg.
2. A rank-four anchored-pair pencil has distinct retained anchors and yields a
   credited anchor endpoint bank through PP3anu--PP3anz.
3. A rank-four, rank-five, or rank-six inserted-triple pencil is impossible by the
   line--coordinate unique-completion theorem PP3aoa--PP3aoc.
4. The required controller-pool, distinguished-endpoint, source-clean, Hall, or
   alternating host fails explicitly.

#### Proof

After PP3aqo fixes the class and variable role, the hypotheses are exactly those
of the cited terminal-source-pencil theorems.  The additional bounded core is part
of their fixed signature and does not affect distinctness of the variable
extensions. ∎

Hence no high-support source class remains terminal.

## 3. Insertion-class pencils

### Theorem PP3aqq -- PROVED / CONDITIONAL EXISTING PETAL AND COMPOSITE INTERFACES

A near-linear terminal pencil of an insertion class is exactly one of:

1. a fixed-axis unary arc pencil `A_2`;
2. a fixed-centre directed path pencil `B_3`;
3. a centre-arc partner pencil `B_4`.

It therefore enters the arc-petal, path/grid, or partner/fan conversion chains.
After complete residual-support selection, its finite local table is either:

1. absorbed by robust final allocation; or
2. cancelled by the one-centre theorem PP3aqa--PP3aqg; or
3. cancelled in full by the bounded-marked zero-cost theorem PP3aqh--PP3aqn; or
4. blocked by an explicit external host failure.

#### Proof

The insertion normal form has only support ranks two, three, and four.  Fixing all
but one variable helper gives exactly the terminal geometries identified in
PP3aoi.  Apply the corresponding petal/grid/fan chain and then the robust or
composite local-table endpoint. ∎

Thus a second-generation insertion pencil does not increase support rank or create
a new weighted object.

## 4. Closed bounded-marked host theorem

### Theorem PP3aqr -- PROVED / CONDITIONAL COMBINED HOST INTERFACE

Let `D` be a set of at most four distinguished local cells to be moved in a second
trade.  Exactly one of the following occurs.

1. There is a `D`-separated independent helper block, giving a source-valid
   zero-insertion-cost trade and cancelling the complete local table.
2. A terminal source pencil yields a credited endpoint bank, source star, or an
   impossible unique-completion configuration.
3. A terminal insertion pencil re-enters `A_2`, `B_3`, or `B_4` and is absorbed or
   cancelled by an established endpoint.
4. A controller-pool, distinguished-endpoint, source-clean, transition, Hall,
   alternating, or matching host fails explicitly.

No diffuse residual support, weighted local table, or recursive new pencil remains.

#### Proof

Apply PP3aqk.  Its independent branch is item 1.  In its terminal-pencil branch,
apply PP3aqo and then PP3aqp or PP3aqq according to the canonical type. ∎

## 5. Bank-level consequence

Suppose a target-size petal or resource bank supplies many candidate first trades,
each with a bounded local inserted set `D_e`.

### Corollary PP3aqs -- PROVED

At least one bank member yields:

1. robust direct completion;
2. a zero-cost bounded-marked composite improvement;
3. a credited source/anchor/transition endpoint bank;
4. a foreign support pencil already belonging to `A_2`, `B_3`, or `B_4`;
5. an explicit external host failure.

Failure cannot be attributed to a new sequence of successively conditioned
terminal pencils.

#### Proof

Apply PP3aqr independently to each bank member.  Every pencil alternative is
closed by PP3aqp--PP3aqq, so no unresolved class is passed to a further level. ∎

## 6. Revised marked-host frontier

### Corollary PP3aqt -- PROVED

The complete marked-support and bounded-multimarked analysis leaves no internal
support obstruction.  The remaining host issues are genuinely external:

1. insufficient controller-disjoint pool size;
2. failure of distinguished endpoint placement;
3. source-clean transition or anchor failure before the canonical support table is
   formed;
4. conditional Hall, alternating, or matching failure;
5. inability to realize the separated cycle while preserving the required pool
   and controller coordinates.

Near-linear terminal pencils, including second-generation pencils, are no longer
independent frontiers.

The no-three-in-line conjecture remains unproved.
