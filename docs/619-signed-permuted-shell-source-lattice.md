# Signed and permuted shell source lattice

The fixed-column obstruction of `docs/613` covered nonnegative composition,
quantization, and chamber transport.  This chapter closes two additional formal
escape routes: cancellation and relabelling of the three cycle coordinates.

## 1. Full integer lattice

### Theorem PP3cvx — PROVED / INDEX-TWO SIGNED SOURCE LATTICE

The integer lattice generated by

```text
(1,0,1), (1,1,0), (0,1,1)
```

is exactly the set of integer vectors with even coordinate sum.  Its determinant
is two.

#### Proof

Solving for the generator coefficients gives half of

```text
(y1-y2+y3, y1+y2-y3, -y1+y2+y3).
```

These are all integral exactly when `y1+y2+y3` is even. ∎

#### Proof

Signed integer combinations remain in the generated lattice.  Coordinate

## 3. Consequence for shell optimization

### Theorem PP3cvz — PROVED / NO FORMAL REOPTIMIZATION ESCAPE
