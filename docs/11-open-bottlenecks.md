# Open bottlenecks and research roadmap

## 1. Current proof status

The no-three-in-line conjecture remains open. Through **CMR2629**, the branch contains exact
noncircular documentary work banks from T01 through T31, typed registries for all 43 atomic targets, the
complete 252-chamber worklist and a final dossier audit.

The branch still lacks the genuine source statements, exhaustive recurrence theorem, actual complete
population, arbitrary-`n` coverage, truth of the semantic claims, global-family exhaustiveness, chamber
proofs, the ten final premise proofs and the reviewed implication to `D(n)=2n`.

Every final checker permanently reports:

```text
all_n_proved_by_checker = 0
```

## 2. T01--T04: close the root and enter the actual population

For T01, transcribe each exact source statement, recompute its UTF-8 digest, supply its fixed-kind proof
artifact and complete ordinary mathematical review.

For T02, populate and prove every case, clause, finite axis, exclusion and global-parent application. Every
application must bind its exact source case, clause and operation slot. Then prove the supplied rule bank
is the genuine exhaustive recurrence.

For T03, enter every literal operation-slot field: points, removals, survivors, fate witnesses, responses,
selectors, vectors, routed credits, loads and transitions. Keep useful data `populated` until its proof
support exists.

For T04, enter every skeleton-derived recurrent block and return/interface/off-diagonal row with exact T03
ancestry. Recurrent blocks need local states, recurrent rows, return routes, interface attachments and
source-clause bindings. Interface rows need target, route, transition and source-clause data.

### 9.2 Canonical premise record

Every premise has one open/proved record with its fixed target, proof mode, dependency target list,

### 9.3 Reviewed implication statement

Every proved premise has exactly one semantic certificate containing:

```text

```

Open premises contain no semantic certificate. Nonempty text is necessary documentary data, not a proof.

### 9.4 Noncircular artifact cores

The premise artifact core excludes its outward locator and digest. The atomic target artifact core excludes
its outward proof locator and digest. The per-premise bundle hashes only:

```text

```

No ancestor certificate SHA is included in the per-premise bundle. This prevents the completion pointer
from occurring inside an ancestor used to define itself.

```text

  locator = final-premise-frontier://PREMISE-ID
  digest  = final_premise_frontier_proof_bundle_sha256

  proof_locator = final-premise-frontier://TARGET-ID
```

artifact.

### 9.6 Synchronization and honesty boundary

Frontier readiness must equal both the effective final-contract premise and the effective T22--T31 atomic
target. Open premise frontiers contain neither artifact.

Passing establishes exact documentary ancestry and noncircular binding. It does not prove any lower target,
does not prove the dependency implication and does not establish arbitrary-`n` coverage.
