# ERL selector-rule review gate

A restored-menu selector claim is admissible only if it distinguishes the normalized source rule from the complete-score audit convention.

## Exact compatibility facts

The normalized selected-provenance rule is

```text
minimum intrinsic triple count, then lexicographically least response.
```

Its source-backed scope is the original residual response family of each normalized side-four host.

The restoration audit rule is

```text
lexicographically least response in the complete-score minimizer face.
```

On the 128 safe menu/background cases, formal intrinsic extension and complete-score selection agree on all selected identities and all next gaps, but only 104 minimizer faces. The 24 disagreements are the restore-both cases in which complete score removes `2301`.

Agreement of selected identity does not prove equality of scoring rules, operation rows, child rows, or payments.

## Menu-specific requirements

```text
blocked:
  normalized source rule directly available
  complete minimizer unique

restore 02:
  restored rule not source-authorized
  complete minimizer tied in all 32 cases
  source tie-break or full face congruence required

restore 20:
  restored rule not source-authorized
  complete minimizer unique in all 32 cases
  physical menu, response-family and score semantics still required

restore both:
  restored rule not source-authorized
  complete minimizer tied in all 32 cases
  minimizer face differs from intrinsic extension in 24 cases
  source tie-break or full face congruence required.
```

## Accepted evidence

Each restored menu must populate:

```text
physical_occurrence_ref
legal_menu_state_ref
response_family_ref
score_semantics_ref
selector_rule_ref
scheduler_operation_ref
child_payment_congruence_ref
realization_status.
```

For a tied face, accept one of:

1. a source scheduler rule that selects one exact response in every relevant context; or
2. a theorem proving every response in the complete minimizer face has congruent operation, child-row and payment behaviour for the recurrent certificate.

The following are insufficient:

```text
the same selected label under a formal intrinsic extension
the same next gap
lexicographic order introduced only by the audit
an installed operation-kind name without first-host mapping
unique-selector stability theorems applied to a tied face
a fixture scheduler at another side
```

Current restored selector imports: **0 of 3**.

Current populated restored-selector fields: **0 of 24**.

This gate does not authorize physical restoration legality, persistent owner identity, operation/payment congruence, recurrent child rows, strict Lyapunov closure, global termination, or `all_n_proved_by_checker=1`.
