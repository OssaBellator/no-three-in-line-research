# Vector residue frontiers for interactions

`docs/512` gives exact scalar residue correctors for one critical interaction
cycle. Several correction plans can tie in minimum work while trading different
omitted-output coordinates. This chapter retains the complete secondary Pareto
frontier in each length residue.

Let `C` be a based critical closed walk of length `P`, scalar work `w(C)`, and
secondary vector `z(C)`. Put `gamma=w(C)/P` and give every edge reduced scalar
work `w'_e=w_e-gamma`.

## 1. Minimum-work residue values

### Theorem PP3ckg -- PROVED / EVENTUAL MIN-PLUS RESIDUE PERIODICITY

If every closed walk has nonnegative reduced work, the minimum reduced work of a
based return in each residue `r mod P` is a shortest-path value in the finite
residue-expanded graph. Therefore, for all sufficiently large `N=qP+r`,

```text
minimum work(N)=q w(C)+alpha_r
```

for a finite rational residue table `alpha_r`.

#### Proof

This is the scalar residue oracle of `PP3cjs`. Zero-reduced-work copies of `C`
advance the length by `P` without changing the residue value, so every large
length is a translation of one finite shortest corrector. ∎

## 2. Secondary Pareto correctors

### Theorem PP3ckh -- PROVED / VECTOR RESIDUE FRONTIER

Assume additionally that every zero-reduced-work closed walk is generated by
copies of `C`. Among all minimum-reduced-work correctors `R` of residue `r`, form
the normalized secondary excess

```text
e(R)=z(R)-[(|R|-r)/P] z(C).
```

After deleting dominated excesses, a finite set `F_r` remains. For every
sufficiently large `N=qP+r`, the complete secondary Pareto frontier among
minimum-work length-`N` walks is

```text
q z(C)+F_r.
```

#### Proof

A minimum-reduced-work corrector can have every removable copy of `C` deleted.
Under the hypothesis, the residue-expanded zero-cost subgraph has no other
closed component, so only finitely many irreducible minimum-work correctors
remain. Reattaching copies of `C` translates all their secondary vectors by the
same amount and therefore preserves Pareto order. ∎

## 3. Stored exact fixture

### Theorem PP3cki -- PROVED / TWO-POINT ODD FRONTIER

The audit `scripts/check_vector_interaction_residue_frontiers.py` uses a critical
length-two block

```text
BC=(work,out_1,out_2)=(5,1,1)
```

and two one-step odd correctors

```text
A=(3,2,0),
D=(3,0,2).
```

For every even length `N=2q`, the minimum-work secondary frontier is the single
point `(q,q)`. For every odd length `N=2q+1`, it is the two-point set

```text
(q+2,q),
(q,q+2).
```

The minimum-work formula is

```text
5 floor(N/2)+3(N mod 2).
```

Independent enumeration verifies the complete minimum-work Pareto frontier for
every length through 128.

## 4. Prime-patching consequence

Finite interaction corrections no longer collapse tied all-length schedules to
one arbitrary scalar witness. Every length residue now carries an exact finite
vector frontier, allowing the later Hall, threshold, and shell budgets to choose
the correct tradeoff.
