# Sparse typed pair/completion-core overlap

This note continues the canonical typed pair/completion-core result on the same complete finite physical-source/neutral-move network. It identifies the exact shared neutral capacity that the remaining physical argument must exclude or pay.

## Contract

For a typed terminal set `S`, let `d(S)` be total sign-pair/completion demand, `F(S)` the maximum physical-source/neutral-move flow with only `S` enabled, and `Delta(S)=d(S)-F(S)`. Retain every pair or completion type, boundary address, neutral move, physical source, capacity and legality edge.

Let `C` be the canonical minimum-cardinality deficient typed core and put `delta=Delta(C)>0`. Every proper subset of `C` is fully payable.

## SAS5kz--SAS5ld

1. Every nonempty proper `A subset C` satisfies `F(A)=d(A)`.
2. Every nontrivial partition `C=A disjoint_union B` has exact competition `Omega(A,B)=F(A)+F(B)-F(C)=delta`.
3. If `C` contains both pair and completion addresses, the pair-versus-completion split is a canonical typed witness of overlap `delta`. If it is type-homogeneous and non-singleton, use the least balanced complete-address split. A singleton is a direct local typed shortage.
4. Any boundary-neutral physical decomposition producing additive payment across one retained split, or merely an overlap upper bound below `delta`, excludes the core.
5. Omitted legal pairs, tasks or moves, merged physical sources, changed boundary state, lost type data or independent reuse of shared neutral capacity is a reset.

## Consequence

A remaining SAS obstruction is either one direct typed shortage or two separately payable pair/completion families whose neutral-move optima overlap by the whole deficit. The next physical step is to separate one canonical split, bound its overlap below `delta`, or charge that exact overlap to a named neutral source or heavy core atom.

## Scope

This theorem is conditional on the complete fixed typed network and exact subset max-flow values. It does not prove SAS6 or the no-three-in-line conjecture.
