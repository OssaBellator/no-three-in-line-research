# Side-ten opposite-pair double-coset obstruction in coarse-row orientations

PX980--PX982 identify the complete one-transposition affine double-coset search
space. The smallest family is generated by the opposite transposition

\[
\tau_5=(0\ 5),
\qquad
|G\tau_5G|=200,
\]

where `G=AGL(1,10)`. This chapter closes that entire double coset in the two
coarse-row orientations.

## 1. Exact search family

For each

\[
T\in G,
\qquad
Q\in G\tau_5G,
\]

run the exact all-transposition row-pattern solver. One geometry includes every
row labeling `P in S_10` and every spanning degree-two selector. There are

\[
40\cdot200=\boxed{8000}
\]

geometries in each orientation.

## 2. Complete coarse-row census

### Theorem PX983 -- PROVED FINITE

No geometry in the opposite-pair double coset contains a no-three spanning
degree-two state in orientation `cc` or `cf`.

The complete deterministic census is:

| Orientation | Geometries | Search nodes | Maximum nodes in one geometry |
|---|---:|---:|---:|
| `cc` | 8,000 | 152,056,230 | 337,026 |
| `cf` | 8,000 | 114,391,525 | 214,783 |
| **Total** | **16,000** | **266,447,755** | **337,026** |

### Proof

The double-coset generator constructs all `200` distinct maps in
`G tau_5 G`, sorted lexicographically. For each of the forty affine `T`, the
PX972 solver assigns every unused abstract pattern to the second row block,
thereby enumerating every `P`, and chooses every two-of-four row state compatible
with column degree two.

A branch is rejected exactly when a newly inserted scalar point forms a zero
integer determinant with two selected points, or when remaining pattern capacity
cannot complete a column. A leaf is accepted only when every scalar row and
column has degree two. All 8,000 geometries in each displayed orientation
terminate without a leaf. \(\square\)

## 3. Orientation reduction

### Corollary PX984 -- PROVED REDUCTION

Any recursive side-ten template with

\[
T\in G,
\qquad
Q\in G\tau_5G
\]

must use a fine-row orientation, `fc` or `ff`.

### Proof

PX983 excludes both orientations whose row coordinate uses concatenated coarse
and fine digits. The two fine-row orientations are the only remaining global
radix choices. \(\square\)

This is an orientation reduction, not a complete obstruction for the opposite
pair double coset.

## 4. Exact replay partition

### Theorem PX985 -- PROVED IMPLEMENTATION REDUCTION

The committed verifier partitions each completed orientation into eighty exact
100-geometry intervals. Every interval independently reconstructs the 200-map
double coset and uses the same search tree inside each geometry. The aggregate
node sums and maxima in PX983 are asserted after interval completion.

The fine-row families have substantially heavier outliers and remain open; no
partial fine-row search is used for a theorem in this chapter.
