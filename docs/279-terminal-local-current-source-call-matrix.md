# Terminal local current/source call matrix

The late prime-patching audit has successively removed raw second-host leaves,
coordinate shortages, residual grid and fan hosts, weighted multiplicity, petal
host failure, completed-state binary support, and paired-secant source-host
failure.  The remaining index still lists unary/source/base-domain current
concentrations as a local frontier.

At the actual fixed-attempt call sites these are not terminal objects.  A failed
base margin or score condition already produces a credited current structure.
A source-valid first package with positive designated credit is followed by the
complete `Theta_E^+` second host.  Its independent branch cancels the complete
first insertion table; its dense current branch is a directly paid canonical
structure; and its dense source branch is terminal by the paired-secant source
routing theorem.

This chapter consolidates those facts into one terminal local call matrix.  It
does not construct the prime-minus-one seed required by the global transfer.

## 1. Exact raw second-host row

Let a source-valid fixed-infrastructure first package insert a marked set `D`
of size `s<=W` and carry positive designated removal credit `C` in

```text
Theta_E^+=Xi_cell+Lambda_E+Xi_old.
```

Partition `D` by source layer and permanent matching block and apply the
complete support table in every nonempty block.

### Proposition PP3bcn -- PROVED

Every block satisfies the marked-scale, quadratic-helper, linear-role-loss, and
rank-at-most-three support hypotheses.  Its raw second-host output is exactly
one of:

1. an independent support-free cycle;
2. dense current support; or
3. dense source support.

There is no raw Hall, alternating, non-superregular, distinguished-endpoint,
role-host, locally impossible, or coordinate-shortage output.

#### Proof

The scale, helper, puncture, and role-domain hypotheses are PP3baa--PP3bah and
PP3bao--PP3bas.  Apply PP3bai--PP3ban to the complete `Theta_E^+` support table
of PP3azu.  Those theorems replace the old explicit-host row by the displayed
trichotomy. ∎

## 2. Independent blocks pay the complete first insertion table

### Proposition PP3bco -- PROVED

If every nonempty block takes the independent branch of PP3bcn, the composite
package satisfies

```text
Theta_final^+-Theta_initial^+ <= -C < 0.
```

The conclusion is independent of the rank, multiplicity, cross-block
distribution, or unary/binary decomposition of the first insertion table.

#### Proof

Every first-step new current incidence meets the inserted set by PP3azs.
The later block cycles delete the complete inserted set and create zero new
incidence.  PP3azt assigns every first insertion incidence to its first later
destruction, and PP3azw gives the displayed inequality. ∎

## 3. Dense current support is terminal

### Theorem PP3bcp -- PROVED / CONDITIONAL ESTABLISHED DIRECT-PAYMENT INTERFACES

A dense-current output of PP3bcn yields one of:

1. strict current potential payment;
2. direct final allocation and patch completion; or
3. a dense-source object entering PP3bcq below.

It cannot terminate in unary multiplicity, binary multiplicity, a raw endpoint
host, or an internal coordinate cover.

#### Proof

The dense table produces a target canonical credited structure by the complete
support decomposition.  Repeated source centres are paid by PP3auf; credited
banks and matchings are paid by PP3aue; the remaining canonical structures are
converted and paid by PP3aug and PP3aud.  Internal coordinate cover is absent
by PP3bao--PP3bas, and raw host failure is absent by PP3bai--PP3ban.

Weighted grids, fans, projective covers, and heavy pencils are absorbed by
PP3bbh--PP3bbn.  Petal host leaves are absent by PP3bbo--PP3bbt.  Every binary
pair-shadow term of a completed state is absorbed by PP3bbu--PP3bby.  Unary
support either fits the final margin by PP3ahk or is a genuine credited source
star by PP3aho--PP3ahp and hence returns to PP3auf--PP3aug.  Any source-typed
remainder enters the dense-source route. ∎

The complete insertion-cancellation route is stronger than separately paying
`A_2`, `B_3`, or `B_4`: those classifications are optional after the first
source-valid package has been selected.

## 4. Dense source support is terminal

### Theorem PP3bcq -- PROVED / CONDITIONAL ESTABLISHED CURRENT PAYMENT

A dense-source output of PP3bcn yields one of:

1. a source-valid joint completion spending the original designated credit;
2. strict named current payment;
3. direct patch completion; or
4. a directly paid fixed-centre source star or credited endpoint bank.

It does not generate another raw cumulative source-host feasibility problem.

#### Proof

Apply PP3bbz--PP3bcf.  Paired-switch two-inserted-cell source mass vanishes at
the adaptive scale, hard unary source support is `Xi_old` credit, and a
fixed-centre dense-source table is a canonical credited source structure.
Those results route every dense-source branch to the displayed outcomes. ∎

## 5. A source-valid credited first package has a terminal endpoint

### Theorem PP3bcr -- PROVED / CONDITIONAL ESTABLISHED LOCAL PAYMENT

Every source-valid fixed-infrastructure first package carrying positive current
removal credit has one of two terminal outcomes:

1. the patch is installed; or
2. the current nonnegative integer potential strictly decreases.

No unary/source/base-domain concentration produced after that package is a
third outcome.

#### Proof

Apply PP3bcn blockwise.  If all blocks are independent, use PP3bco.  A dense
current block is terminal by PP3bcp, and a dense source block is terminal by
PP3bcq.  The alternatives are exhaustive. ∎

## 6. Failed fixed attempts also have no local leaf

### Theorem PP3bcs -- PROVED / CONDITIONAL ESTABLISHED FIXED-ATTEMPT INTERFACES

For one controller-aware fixed allocation attempt, exactly one of the following
occurs:

1. the simultaneous saturated no-three macro patch is installed; or
2. a pool-compatible source-valid repair strictly decreases the current
   fixed-infrastructure potential.

A failed base margin, score numerator, unary domain, active-anchor table, or
source-host table is not terminal.

#### Proof

If an individual label margin fails, PP3aur extracts a credited star or bank.
If the two-sided score condition fails, PP3aus--PP3aut extract a credited
current structure.  Active-anchor failure is cleared or paid by
PP3avn--PP3awb.  Source-host output is terminal by PP3bcq.  Every credited
current object is paid by PP3bcp, while a source-valid first package is terminal
by PP3bcr.  The successful score branch installs the patch by PP3ho--PP3hq. ∎

## 7. Local finite termination

### Theorem PP3bct -- PROVED / CONDITIONAL FIXED SLAB SETUP

Fix the slab coordinate pools, numerical labels, candidate-cell universe, and
the standard patch-only and ordinary source-anchor energy hypotheses of the
slab-optimal construction.  Starting from any saturated no-three source on the
old square, repeated fixed attempts terminate after finitely many repairs with
an installed exact-width macro patch.

No additional current-conversion, source-host, restart-comparability,
coordinate-cover, or endpoint-host hypothesis remains in this local call
matrix.

#### Proof

The fixed candidate universe and zero-mass activation rule compare consecutive
potentials by PP3aux--PP3avf.  Theorem PP3bcs gives patch completion or strict
decrease at each attempt.  The potential is a nonnegative integer, so the
strict branch cannot repeat indefinitely.  Apply the heterogeneous exact-width
assembly PP3awr--PP3aww at the successful attempt. ∎

The statement is local: it begins with a saturated source and does not assert
that the required prime-minus-one sources exist asymptotically.

## 8. Revised frontier

### Corollary PP3bcu -- PROVED

Within the fixed-infrastructure slab architecture, the local current/source call
matrix is terminal.  The following are no longer live frontiers:

- unary or binary insertion multiplicity after a source-valid package;
- current base-domain or score-numerator failure;
- active-anchor restart failure;
- dense source-host feasibility;
- raw Hall, alternating, non-superregular, role-host, or coordinate leaves; and
- restart comparability across failed attempts.

The separate global theorem is now exact: construct a saturated no-three seed
on `[p-1]^2` for every sufficiently large prime `p`.  The no-three-in-line
conjecture remains unproved.
