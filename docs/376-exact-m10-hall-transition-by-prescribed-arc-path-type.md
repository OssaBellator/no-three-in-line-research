# Exact `m=10` Hall transition by prescribed-arc path type

`docs/373` resolves the inverse-source transition by compatible-source count.
The constant-one envelope first fails at source count `209`, is intermittent
through `287`, and then fails at every later nonempty count maximum.  This
chapter asks whether the transition window is explained by the connectivity of
the three prescribed Hamilton arcs.

The answer is negative: every path-forest type occurs on both sides of the
constant-one boundary.

No asymptotic inverse-source theorem is claimed.

## 1. Three prescribed arcs have three path-forest types

An extendible atomic flaw prescribes three directed arcs with distinct tails and
distinct heads.  By `PP3bpn`, the prescribed graph is a directed path forest
with no proper directed cycle.

### Proposition PP3btq -- PROVED / THREE ARC-CONNECTIVITY TYPES

The prescribed path forest has exactly one, two, or three connected components:

```text
1 component:  one directed three-edge path;
2 components: one directed two-edge path plus one disjoint arc;
3 components: three disjoint directed arcs.
```

These cases are exhaustive and mutually exclusive.

#### Proof

Every component of the prescribed graph is a directed path containing at least
one of the three arcs.  Partitioning three arcs among nonempty path components
gives only `3`, `2+1`, or `1+1+1`. ∎

## 3. Connectivity is informative but not decisive

### Corollary PP3bts -- PROVED / VERIFIED FINITELY / ARC TYPE IS NOT A SUFFICIENT STATISTIC

Each of the three path-forest types contains both constant-one violations and
nonviolations.  Therefore prescribed-arc connectivity alone cannot characterize
the Hall transition.

The type statistics still show two distinct effects:

1. three disjoint arcs have the highest violation frequency, `1/3`;
2. the largest type-conditioned obstruction, `51152/38383`, occurs for a
   two-edge path plus one arc.

Thus neither connectivity nor compatible-source count is sufficient by itself.
A structural inverse-support theorem must also control the weighted clean-target
neighbourhood generated by the prescribed arcs and parity compatibility.
