# Orbit-phase typed occurrence-slot assignment Hall core

This block converts localized residual/edit collisions into a complete finite typed use-to-source-slot assignment problem. It is conditional on complete source, unit, valuation, holonomy and legality data.

## OP4ey: typed unit assignment network

Let `U` be the localized typed residual/edit use claims and `S` the faithful unit-sensitive physical-source occurrence slots. Join `u` to `s` exactly when the complete residual or edit type, unit class, valuation vector, holonomy, factor, source and legality fields permit that debit. The unit network `source -> U -> S -> sink` has integral maximum flow equal to the largest injective one-use realization.

## OP4ez: exact typed Hall criterion

All residual/edit uses have injective one-use source lineage if and only if the maximum matching has size `|U|`, equivalently `|N(X)| >= |X|` for every typed use set `X`. A complete matching debits each physical source slot once and excludes duplicate consumption and non-injective source reuse.

## OP4fa: canonical typed maximum-deficit core

If the maximum matching size is `nu<|U|`, put `delta=|U|-nu`. Among all subsets with `|X|-|N(X)|=delta`, choose minimum cardinality and then the lexicographically least complete unit-sensitive address. The returned `X_*` preserves residual/edit type and every retained quotient field; every proper subset has deficit below `delta`.

## OP4fb: saturation and essentiality

A maximum matching on `X_*` saturates every slot in `N(X_*)`, leaves exactly `delta` typed uses unmatched and preserves all source, unit, valuation and holonomy addresses. Removing any retained use lowers the maximum core deficit by at least one.

## OP4fc: physical interface and resets

Thus each localized typed collision is resolved by an injective assignment or returns one exact residual/edit Hall core. Remaining work is proving Hall from concrete source creation and unit-sensitive compatibility, adding named source deposits, or excluding/paying the returned core. Omitted types or quotient fields, hidden source creation, changed valuation/holonomy, splitting, relabelling or reuse reset the theorem.

This theorem does not prove OP5 or the no-three-in-line conjecture.
