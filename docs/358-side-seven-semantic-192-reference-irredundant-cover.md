# Side-seven semantic 192-reference irredundant cover

This chapter compresses the exact semantic vocabulary generated by the first 192 clean-top references for multiplicity-two case zero, orientation three. It covers the 204 clean top orders reached by those keys; it does not yet cover the complete clean-top family and it does not prove that the selected basis is minimum.

## PX1163 — exact key-union instance

The 192 references generate:

- 150 distinct relaxed semantic keys;
- an exact union of 204 clean top orders;
- 2,832,480 bottom-permutation checks while independently replaying both selector covers on every key extension.

Every key is represented by its pair-support mask and the reference values on that support. Repeated references with the same key are collapsed before set cover is computed.

## PX1164 — deterministic compact cover

The deterministic maximum-uncovered greedy algorithm chooses 116 keys. Reverse deletion, processed in reverse greedy order, removes one redundant key and leaves an irredundant 115-key basis.

Thus 35 of the 150 vocabulary keys can be removed while preserving the complete 204-top union. This is an exact reproducible upper bound, not a minimum-cardinality claim.

The greedy marginal gains begin

```text
6,6,4,4,4,4,4,4,4,4,4,4,4,4,4,4,4,3,3,2,...
```

and finish with single-top gains. The small gains explain why the current vocabulary does not yet compress to a tiny master dictionary.
