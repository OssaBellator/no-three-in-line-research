# Exact coordinate-orbit CSP for four side-seven selectors

PX499--PX500 separate a side-seven full-selector state into an abstract
spanning degree-two selector and three coordinate orderings.  This chapter fixes
the four best abstract selectors underlying PX501 and exhausts every coordinate
ordering, not merely the local transposition boxes of PX502.

## 1. Coordinate variables for a fixed abstract selector

Write an abstract row as `(i,z)`, where `i` is the outer row bit and `z` is the
relative-cycle label.  Write an abstract column as `(j,w)`.  Fix a spanning
degree-two selector `F` in the four-regular host

\[
(i,z)\longrightarrow(j,z),
\qquad
(i,z)\longrightarrow(j,H(z)).
\]

The scalar embedding is determined by three permutations

\[
A_0,A_1,R\in\operatorname{Sym}([7]).
\]

Here `R(z)` is the scalar fine-row position of the bottom abstract row `(1,z)`,
while the top row order is gauge-fixed.  In an orientation
`epsilon_x epsilon_y`, the selected abstract edge `(i,z;j,w)` becomes

\[
x=
\begin{cases}
z,&i=0,\ \epsilon_x=c,\\
7+R(z),&i=1,\ \epsilon_x=c,\\
2z,&i=0,\ \epsilon_x=f,\\
2R(z)+1,&i=1,\ \epsilon_x=f,
\end{cases}
\]

and

\[
y=
\begin{cases}
7j+A_j(w),&\epsilon_y=c,\\
2A_j(w)+j,&\epsilon_y=f.
\end{cases}
\]

### Theorem PX504 -- PROVED

For a fixed abstract selector, existence of a scalar no-three embedding is
exactly a finite constraint-satisfaction problem with 21 variables:

- seven values of `A_0`;
- seven values of `A_1`;
- seven values of `R`;

with one all-different constraint on each group.

Every collinear-triple constraint involves three distinct abstract column
vertices.  Therefore it is a ternary forbidden-assignment constraint after the
required row and column variables have been exposed.

### Proof

The coordinate formula gives the forward and reverse correspondence between
permutation assignments and scalar embeddings.  Every abstract column vertex
has selected degree two, so it produces exactly two scalar points with the same
`y` coordinate.  A real line through those two points is vertical.  No third
selected point has the same scalar column, hence a bad triple cannot use both
points of one abstract column.  It therefore uses three distinct abstract
columns, and its determinant is a ternary constraint on their assigned column
positions together with any bottom-row variables involved. \(\square\)

The exact solver branches on the unassigned variable with the fewest currently
legal values.  Whenever a point becomes fully positioned, every newly completed
triple is checked by integer determinant.

## 2. The four centre selectors

Convert each PX501 centre witness from scalar-row notation to abstract row
notation by replacing a bottom scalar row `u` with its cycle label `P(u)`.  This
produces one fixed abstract selector for each relative type

\[
(7),\qquad(5,2),\qquad(4,3),\qquad(3,2,2).
\]

Each selector has degree two at every abstract row and column.  Varying `R`
recovers every bottom-row ordering, while arbitrary `A_0,A_1` recover every pair
of column-block orderings.

### Theorem PX505 -- PROVED FINITE

None of the four fixed abstract selectors has a no-three scalar embedding for
any

\[
(A_0,A_1,R)\in S_7^3
\]

and any of the four radix orientations.

The exact CSP node counts are:

### Proof

The verifier reconstructs each abstract selector from the recorded PX501
centre, checks abstract row and column degree two, and runs the 21-variable CSP
in each orientation.  Every leaf or pruned branch uses exact all-different and
integer-determinant tests.  All sixteen searches are empty and their node counts
are asserted. \(\square\)

### Corollary PX506 -- PROVED FINITE

For one selector, the theorem rejects

\[
4(7!)^3
=
512{,}096{,}256{,}000
\]

raw coordinate assignments.  Across the four selectors it rejects

\[
\boxed{2{,}048{,}385{,}024{,}000}
\]

assignments.

This raw count is an assignment count, not a claim that all resulting scalar
hosts are pairwise distinct.

## 3. Updated structural boundary

### Corollary PX507 -- PROVED REDUCTION

A successful side-seven construction cannot keep any of the four PX501
abstract selectors and repair it solely by reordering the bottom rows or the two
column blocks.  Thus the next search must change the abstract selector itself.

The exact remaining finite problem is now:

1. traverse the abstract selector space generated by PX500 alternating cycles;
2. quotient selectors by relative-cycle and scalar reflection symmetries;
3. run the coordinate CSP only on selector representatives;
4. either find one embeddable selector per relative class or prove an
   orientation-independent selector obstruction.

PX505 does not rule out other abstract selectors.
