# Two-switch generation of threshold trades

`docs/617` identifies eight nearest legal degree-four threshold matrices, each a
unit alternating three-cycle trade from the stored source matrix.  This chapter
shows that every trade is generated by two nonnegative conservative `2x2`
switches.

A switch on rows `r,s` and columns `a,b` adds one to one diagonal of the selected
rectangle and subtracts one from the other.  It preserves all row and column
margins.  Only switches whose intermediate matrix remains nonnegative are used.

## 1. Complete two-switch generation

### Theorem PP3cwj -- PROVED / ALL EIGHT TARGETS HAVE NONNEGATIVE TWO-SWITCH PATHS

Each of the eight nearest legal degree-four matrices is reachable from the
stored source matrix by exactly two nonnegative conservative switches.

#### Proof

The checker enumerates all eighteen legal permutation layers and all 4,475
matrices decomposable into four ordered legal layers.  It identifies the eight
nearest targets at entrywise distance six.  Breadth-first search over every
nonnegative conservative switch finds a length-two path to each target. ∎

## 2. Switch-distance minimality

### Theorem PP3cwk -- PROVED / TWO SWITCHES ARE NECESSARY

No nearest target is reachable by one switch.

#### Proof

A nontrivial unit `2x2` switch changes exactly four entries by one and therefore
has entrywise `l_1` distance four.  Every nearest legal target has distance six
from the source matrix. ∎

## 3. Canonical generated target

### Theorem PP3cwl -- PROVED / EXPLICIT CONSERVATIVE GENERATION WITNESS

The lexicographically first target

```text
1 1 1 1
0 2 1 1
2 0 1 1
1 1 1 1
```

is generated by the two switches

```text
( rows 0,2 ; columns 0,2 ; sign -1 )
( rows 0,3 ; columns 2,3 ; sign -1 ).
```

Every intermediate matrix is nonnegative and has all row and column sums equal
to four.

#### Proof

Direct substitution gives the displayed target and preserved margins.  The
checker verifies the same properties for all eight paths. ∎

## Consequence

The required threshold repair is no longer an abstract six-edge trade: it lies
at switch distance two in the conservative matrix kernel.  What remains is a
geometric source lemma realizing one conservative `2x2` switch as a legal
prime-patching operation.
