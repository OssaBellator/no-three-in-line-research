# Recurrent-row population coverage by selected operation slots

A common-weight block may contain exact rows without showing which clause-generated,
populated operation each row represents. This chapter binds every declared SCC parent to
one selected populated slot while publishing the complete candidate set.

## Theorem CMR2206 — PROVED AS AN INTERFACE

One certificate composes:

1. a validated parent-rule clause manifest;
2. a slot-covered fibre-batch conformance certificate; and
3. a common-weight recurrent-block certificate.

The slot registry inside the populated batch must equal exactly the registry generated by
the clause manifest.

## Theorem CMR2207 — PROVED

For each declared SCC parent state `p`, the checker reconstructs the complete candidate set

\[
\boxed{C(p)=\{\text{operation slots whose parent state is }p\}.}
\]

A row-selection record must publish exactly `C(p)`, not a hand-picked subset.

## Theorem CMR2208 — PROVED

Each parent selects one slot from `C(p)` and one populated fibre assigned to that slot.
The selected slot must be present in the population audit, and the selected fibre must
agree with the slot/fibre assignment.

## Theorem CMR2209 — PROVED

The selected slot's parent state must equal the common row's parent state. The selected
fibre ID and routing-certificate digest must equal the fibre and route used by the
common-weight row.

Thus a recurrent row cannot be attached to a different populated operation by changing
only an external selection table.

## Theorem CMR2210 — PROVED

The selection records cover the declared SCC state list exactly. Missing parents,
duplicate parent selections and selections for states outside the block are rejected.

The batch publishes the number of candidate and unselected candidate slots per parent.

## Theorem CMR2211 — PROVED

Define the relative completion flag

\[
\boxed{
\text{slot batch complete}\land
\text{common block complete strict SCC}.
}
\]

When both inputs pass, every declared SCC parent has one selected populated row under the
same clause-generated expected universe.

## Theorem CMR2212 — HONEST POLICY BOUNDARY

This composition does not prove that the supplied row-selection reason is the genuine
mathematical policy, that unselected candidate operations are dominated, or that the
clause manifest is the genuinely exhaustive parent rule.

## Corollary CMR2213 — EXECUTABLE ENDPOINT

`scripts/check_prime_power_recurrent_population_coverage.py` validates registry identity,
complete candidate sets, populated selected slots, fibre/route linkage, exact SCC-parent
coverage and the relative complete-strict-population flag.

The script was syntax-compiled in the publication environment. No genuine closed recurrent
population is claimed.
