# Burnside orbits of optimal prefix codes

`docs/474` reconstructs and counts all labeled optimal prefix codes.  Many of
those codes differ only by permutations of equal-risk bank labels or by
survival-preserving automorphisms of the prefix tree.  This chapter counts and
canonically represents the genuine symmetry classes.

Fix a finite set `Omega` of labeled optimal codes.  Let `G` be a finite group
generated by permutations within equal-risk classes and rooted tree
automorphisms that preserve every symbol-survival label.

## 1. Symmetry preservation

### Theorem PP3cfw -- PROVED / OPTIMAL-CODE GROUP ACTION

The natural action of `G` on leaf labels and prefix-tree positions preserves
prefix-freeness, every realized leaf risk, and optimality.  Hence `G` acts on
`Omega`, and every orbit consists entirely of interchangeable optimal schedules.

#### Proof

Class-preserving label permutations do not change base risks.  Allowed tree
automorphisms preserve the survival product on every transported root-to-leaf
path.  Bijectivity preserves prefix-freeness and the complete label set, so the
maximum realized risk is unchanged. ∎

## 2. Exact orbit count

### Theorem PP3cfx -- PROVED / BURNSIDE OPTIMIZER ENUMERATION

The number of symmetry-distinct optimal codes is

```text
|Omega/G|=(1/|G|) sum_(g in G) |Fix_Omega(g)|.
```

Every fixed-point count is finite and exact.  The sum therefore gives a rational
integer certificate for the number of genuine optimizer types.

#### Proof

Count pairs `(g,omega)` with `g omega=omega` first by group elements and then by
orbits.  An orbit with stabilizer size `s` contributes `|orbit| s=|G|` such
pairs.  Dividing the total by `|G|` gives one per orbit. ∎

## 3. Canonical representatives

### Theorem PP3cfy -- PROVED / ORBIT--STABILIZER CODE CERTIFICATE

Order all labeled code descriptions lexicographically.  The least element of an
orbit is a canonical representative.  Storing that representative, a generating
set for `G`, and its stabilizer gives the exact orbit size

```text
|G|/|Stab(omega)|.
```

A complete finite audit checks the generators, canonical minimality, stabilizer,
and the partition of `Omega` into disjoint orbits.

#### Proof

Every finite orbit has a unique least element.  Orbit--stabilizer gives the size,
and explicit group enumeration verifies all stated finite conditions. ∎

## 4. Stored exact fixture

The audit `scripts/check_prefix_code_burnside_orbits.py` uses four equally deep
leaves `00,01,10,11`, with two labels in each of two equal-risk classes.  There
are 24 labeled optimal codes.  The class-preserving label group has order four,
the full depth-two tree automorphism group has order eight, and the combined
group has order 32.  The Burnside fixed-point sum is 64, so there are exactly two
symmetry orbits, of sizes eight and sixteen.  Their canonical forms are the
sibling-class pattern

```text
(A1,A2,B1,B2)
```

and the split-class pattern

```text
(A1,B1,A2,B2).
```

## 5. Prime-patching consequence

The large optimizer counts from quotient reconstruction can now be compressed to
a small set of genuinely different marker schedules.  Later geometric filters
need test only canonical orbit representatives, while orbit sizes retain the
exact amount of labeling freedom.
