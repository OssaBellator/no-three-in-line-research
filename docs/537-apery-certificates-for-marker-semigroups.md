# Apéry certificates for marker semigroups

`docs/531` proves saturation of mixed critical marker lengths.  This chapter
replaces a bare conductor claim by an explicit residue witness table.  The table
both proves that every large side length is attainable and reconstructs a
minimum-cost deterministic marker schedule.

Let the critical marker blocks have positive integer lengths
`L={ell_1,...,ell_s}` with gcd one, common mean cost `mu`, and deterministic
action vectors `a_i`.  Put `m=min L` and let `S=<L>` be the numerical semigroup
generated by the critical lengths.

## 1. Apéry witness table

### Theorem PP3cml -- PROVED / MARKER APÉRY CONDUCTOR CERTIFICATE

For every residue `r mod m`, define

```text
omega_r=min{n in S : n congruent r mod m}.
```

Then the finite set `Ap(S,m)={omega_0,...,omega_(m-1)}` satisfies

```text
c(S)=max_r omega_r-m+1,
```

and every integer `N>=c(S)` belongs to `S`.  Moreover, if
`N=omega_r+qm`, an Apéry witness for `omega_r` followed by `q` copies of an
`m`-block is an explicit critical schedule of length `N` and cost `mu N`.

#### Proof

Minimality of `omega_r` implies `omega_r-m` is not in `S`.  Closure under adding
`m` shows every integer in the same residue at or above `omega_r` lies in `S`.
The largest excluded integer is therefore `max_r(omega_r-m)`, giving the
conductor formula.  Concatenating the stored witness with `m`-blocks proves the
reconstruction statement. ∎

## 2. Reduced-cost residue correction

### Theorem PP3cmm -- PROVED / APÉRY REDUCED-COST ORACLE

Suppose a finite marker catalogue also contains noncritical blocks with strictly
positive reduced cost

```text
Delta_i=cost_i-mu ell_i>0.
```

A shortest-path computation on residues modulo `m`, with arc length `Delta_i`
and residue increment `ell_i`, returns for every attainable residue a minimum
reduced-cost corrector.  Combining that corrector with the Apéry table gives an
exact eventual formula

```text
F(N)=mu N+eta_(N mod m)
```

and an explicit schedule for every sufficiently large attainable `N`.

#### Proof

Critical `m`-blocks have zero reduced cost and preserve residue.  Any
minimum-reduced-cost corrector contains only finitely many positive-cost arcs,
so a finite residue shortest-path problem finds it.  Once its length is reached,
zero-cost `m`-blocks extend the schedule without changing reduced cost. ∎

## 3. Two-generator rate mesh

### Theorem PP3cmn -- PROVED / APÉRY RATE-LATTICE CERTIFICATE

For two coprime critical lengths `p,q`, all representations

```text
N=pa+qb
```

in one fixed length slice differ by the lattice move `(a,b)->(a-q,b+p)`.
Consequently adjacent deterministic action-rate vectors differ by at most

```text
(||q a_P-p a_Q||_1)/N.
```

Thus every attainable large slice has an explicit `O(1/N)` rate mesh inside the
critical rate segment, and its endpoints and gaps are certified by integer
representations alone.

#### Proof

Subtracting two representations gives `p Delta a+q Delta b=0`; coprimality
forces `(Delta a,Delta b)=t(q,-p)`.  Dividing the corresponding action-vector
difference by `N` gives the bound. ∎

## 4. Stored exact fixture

The audit `scripts/check_apery_marker_certificates.py` uses critical blocks

```text
P: length 4, cost 4, action (4,0),
Q: length 7, cost 7, action (0,7),
```

and one unit corrector of cost two.  With modulus four,

```text
Ap(S,4)=(0,21,14,7),
c(S)=18.
```

The exact minimum cost is `F(N)=N` for every `N>=18`.  All critical
representations through length 500 are enumerated, and adjacent action-rate
vectors have `N` times their `l_1` gap at most 56.

## 5. Prime-patching consequence

A mixed-length boundary controller now carries a finite, inspectable witness for
every large side length.  The conductor, residue correction, deterministic word,
and finite-length rate error all come from one Apéry certificate rather than
from an existence-only semigroup argument.
