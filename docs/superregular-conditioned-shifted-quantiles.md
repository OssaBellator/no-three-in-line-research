# Conditioning-stable shifted endpoint quantiles

**Branch:** `research/superregular-resampling`

SRR2s--SRR2u bound the minimum event-flow cost when every flawed state excludes
at most `Delta` candidate endpoints.  A remote partial matching or protected
assignment may additionally delete a fixed endpoint set.  This note shows that
conditioning merely adds its deletion rank to the same quantile shift.

Let `Gamma subseteq A x B` satisfy Hall's condition and assume

\[
|B\setminus N_\Gamma(a)|\le\Delta
\qquad(a\in A).
\]

Let `D subseteq B` be a fixed set of endpoints forbidden by conditioning, with
`|D|=k`, and put `B'=B\setminus D` and

\[
\Gamma'=\Gamma[A,B'].
\]

Assume `Gamma'` still satisfies Hall's condition.

## SRR2v -- conditioned left-hole bound -- PROVED

Every `a in A` excludes at most `Delta+k` endpoints of the original endpoint
set and at most `Delta` host-invalid endpoints inside `B'`:

\[
|B\setminus N_{\Gamma'}(a)|\le\Delta+k,
\qquad
|B'\setminus N_{\Gamma'}(a)|\le\Delta.
\]

### Proof

The first complement is contained in `(B\setminus N_\Gamma(a)) union D`.  The
second removes the conditioning set before taking the complement. QED.

## SRR2w -- conditioned shifted-quantile bound -- PROVED

Let `c:B->Z_{>=0}` and write the costs on `B'` in nondecreasing order

\[
c'_{(1)}\le\cdots\le c'_{(|B'|)}.
\]

If `|B'|>=|A|+Delta`, then the conditioned switching graph has a saturating
matching of cost at most

\[
\boxed{
\operatorname{OPT}_{\Gamma'}(c)
\le
\sum_{i=1}^{|A|}c'_{(i+\Delta)}.
}
\]

Equivalently, if one insists on using the original global cost order, then

\[
\boxed{
\operatorname{OPT}_{\Gamma'}(c)
\le
\sum_{i=1}^{|A|}c_{(i+\Delta+k)}.
}
\]

whenever `|B|>=|A|+Delta+k`.

### Proof

Apply SRR2t to `Gamma'` using the second bound in SRR2v.  Deleting `k` elements
from an ordered list can move the `j`-th surviving element rightward by at most
`k`, giving the original-order form. QED.

## SRR2x -- bounded remote conditioning cost -- PROVED

Let `E` be an event multiset with endpoint multiplicity `m_E(b)`.  Under the
conditioned stationary flow normalization, one feasible flaw-removing flow
satisfies

\[
\boxed{
\sum_{C\in E}\Pr(Y\in C\mid D)
\le
\frac1{|A|}
\sum_{i=1}^{|A|}m'_{(i+\Delta)},
}
\]

where `m'` is the multiplicity order on `B'`.

In particular, a compatible remote rank-`k` assignment costs only an additive
`k` positions in the original endpoint quantile order.  No independence or
uniform random deletion assumption is used.

### Proof

Use SRR2i on the conditioned switching graph and apply SRR2w to the endpoint
cost `c=m_E`. QED.

## Consequence for SRR2

For bounded-rank remote conditioning, the quantitative problem is now reduced
to two exact checks:

1. Hall feasibility survives deletion of the conditioned endpoint set;
2. the actual event multiplicities have enough low-cost endpoints after the
   additive `Delta+k` quantile shift.

The remaining superregular work is to prove these facts uniformly for the
bounded-cycle switching graphs generated by the host geometry.

## Finite check

`scripts/verify_srr_conditioned_shifted_quantiles.py` exhausts small Hall graphs,
conditioning sets and endpoint costs.  It compares the exact conditioned
minimum matching cost with both shifted-quantile bounds.
