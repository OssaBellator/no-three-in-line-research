# Side-ten transposition double-coset search space

PX970 rules out affine column pairs for the side-ten all-transposition relative
class. A deterministic non-affine sample finds no witness, but random sampling
does not identify the correct structured family. The first exact enlargement is
the union of affine double cosets generated by one transposition.

Let

\[
G=\operatorname{AGL}(1,10),
\qquad |G|=40.
\]

## 1. Transposition orbits

For an unordered pair `{x,y}` in `Z/10Z`, the affine conjugacy class is determined
by the unit orbit of the cyclic difference `y-x`. There are exactly three types,
represented by

\[
\tau_1=(0\ 1),
\qquad
\tau_2=(0\ 2),
\qquad
\tau_5=(0\ 5).
\]

### Theorem PX980 -- PROVED FINITE/GROUP-THEORETIC

The `G`-conjugacy orbit sizes of these transpositions are respectively

\[
\boxed{20,20,5}.
\]

They partition all `45` transpositions in `S_10`.

### Proof

An affine map multiplies a difference by a unit in

\[
\{1,3,7,9\}.
\]

The nonzero differences therefore split into the three unit orbits

\[
\{1,3,7,9\},
\quad
\{2,4,6,8\},
\quad
\{5\}.
\]

For an unordered pair, the first two types contain
`10*4/2=20` pairs each and the opposite type contains `10/2=5` pairs. Direct
conjugation enumeration agrees with these counts. \(\square\)

## 2. Exact double-coset sizes

### Theorem PX981 -- PROVED FINITE/GROUP-THEORETIC

The three affine double cosets have sizes

\[
|G\tau_1G|=800,
\qquad
|G\tau_2G|=800,
\qquad
|G\tau_5G|=200.
\]

They are pairwise disjoint. Their stabilizer-intersection sizes are

\[
|G\cap\tau_1G\tau_1^{-1}|=2,
\qquad
|G\cap\tau_2G\tau_2^{-1}|=2,
\qquad
|G\cap\tau_5G\tau_5^{-1}|=8.
\]

### Proof

For any finite group and element `tau`,

\[
|G\tau G|
=
\frac{|G|^2}{|G\cap\tau G\tau^{-1}|}.
\]

Exact enumeration of the forty affine permutations gives the three intersection
sizes. Substitution yields `1600/2`, `1600/2`, and `1600/8`. Double cosets are
either equal or disjoint; the verifier checks that the three representative sets
are distinct and have union size

\[
800+800+200=\boxed{1800}.
\]

\(\square\)

This corrects a tempting undercount: searching one representative left coset
`tau G` tests only forty column maps, not the complete double coset.

## 3. Exact recursive geometry count

### Corollary PX982 -- PROVED REDUCTION

If the first column labeling remains affine and the second belongs to one of the
three one-transposition double cosets, then the complete side-ten
all-transposition search contains

\[
40(800+800+200)=\boxed{72{,}000}
\]

column geometries per radix orientation and

\[
4\cdot72{,}000=\boxed{288{,}000}
\]

geometries across all four orientations.

The executable

`scripts/search_product_transposition_double_coset_ten.cpp`

constructs each double coset canonically, sorts and deduplicates its column maps,
and runs any contiguous pair interval through the exact PX972 row-pattern
solver. Every geometry still includes arbitrary `P` and every spanning
degree-two selector.

A `FOUND` output is a complete scalar witness. A `NONE` output is an exact
interval obstruction with deterministic node totals. No complete 288,000-geometry
census is claimed in this chapter.

## 4. Search plan

The next structured recursive task is now finite and correctly partitioned:

1. search the `distance=5` double coset first, because it has only 8,000
   geometries per orientation;
2. then search the two 32,000-geometry families in load-balanced intervals;
3. promote any witness immediately;
4. if all intervals fail, record one exact digest or node census per interval;
5. only after this complete double-coset census move to higher-complexity map
   families.

This search-space theorem does not itself rule out a recursive template.
