# Elimination of the internal coordinate-cover leaf

The dense current-support row PP3bac enters the direct paid-trade layer
PP3auc--PP3aui.  Some of those earlier statements retain a possible
near-complete reserved-coordinate cover.  The later slab reservation census
PP3auj--PP3auo proves that this alternative cannot be generated by the
prime-patching architecture.

This chapter reconciles the two theorem generations.  It removes the internal
coordinate-cover leaf from the second-host current row.  It does not pay the
remaining typed arc-petal, path-petal, choice-grid, partner-fan, or other
explicit conversion objects.

## 1. Exact reservation data at a current-row call

Let a dense current-support block produce a credited marked set of size `h`.
By PP3bac and hereditary truncation,

```text
1<=h<=W.
```

### Proposition PP3bao -- PROVED

At every current-row call inside the slab-optimal fixed infrastructure, the
unavailable old-coordinate set is contained in:

1. the permanent slab union of size
   ```text
   MR=(ab+o(1))m
   ```
   for fixed `ab<1`;
2. an additional internal set of size
   ```text
   O(MW+W+q)=o(m);
   ```
3. the current marked set and bounded role reservations.

All local source, transition, anchor, endpoint-shadow, and insertion
restrictions belong to the complete support table rather than the coordinate
reservation set.

#### Proof

The first two items are PP3auj--PP3auk.  The current marked size and role losses
are supplied by PP3bac.  PP3auk explicitly excludes finite local support events
from the coordinate census, and PP3bai places those events in role domains or
the complete rank-at-most-three support hypergraph. ∎

## 2. Quadratic helper supply dominates every current marked size

### Theorem PP3bap -- PROVED

For every fixed constant `C>0` and every current credited marked set with
`1<=h<=W`, the available old-index set in either current permutation layer
satisfies

```text
available indices > C h^2
```

for all sufficiently large `m`.

The same bound remains valid after splitting the marked set across permanent
matching blocks and processing the blocks sequentially.

#### Proof

PP3aul gives

```text
available indices
> (1-ab-o(1))m
> C h^2,
```

because

```text
h^2<=W^2=Theta(R)=m^(19/20+o(1))=o(m).
```

PP3aum applies the estimate simultaneously to both layers and throughout a
bounded layerwise package.  Permanent-block processing only adds `O(W)`
temporary reservations, already included in the `o(m)` term. ∎

## 3. The exogenous-cover alternative is empty in this architecture

### Corollary PP3baq -- PROVED

The near-complete coordinate-cover alternatives in PP3aua and PP3aue cannot
occur at a dense current-support call produced by PP3bac.

Any failure of quadratic helper supply would require an additional external
reservation of size

```text
(1-ab-o(1))m
```

that is not part of the stated prime-patching construction.

#### Proof

This is PP3aun--PP3auo applied with `s=h`.  Proposition PP3bao verifies that the
current-row call has exactly the internal reservation census used there.
Theorem PP3bap supplies the required helper reservoir. ∎

## 4. Revised dense current-support row

### Theorem PP3bar -- PROVED / CONDITIONAL TYPED CONVERSION ENDPOINTS

A dense current-support output of the complete second host has exactly one of
the following outcomes.

1. A pool-compatible direct marked cycle creates zero `Theta_E^+` insertion and
   strictly spends the newly designated current credit.
2. Complete support failure produces a typed current star, bank, matching,
   anchor structure, insertion pencil, arc-petal, path-petal, choice-grid,
   partner-fan, or fixed-core object entering its stated conversion theorem.

It does not terminate in:

- coordinate shortage;
- a near-complete internal reservation cover;
- raw role-host failure; or
- an untyped distinguished-endpoint, Hall, alternating, or non-superregular
  output.

#### Proof

Use PP3bac to obtain the marked current structure and its designated credit.
The complete support and buffered assignment alternatives are PP3bai--PP3bak.
The independent branch is direct payment by PP3auc--PP3aue and PP3axg.
The coordinate alternative is excluded by PP3baq.  The raw host alternatives
are excluded by PP3bal.  Dense support is therefore already one of the typed
canonical objects listed by PP3awm and PP3aoi. ∎

The conditional status now belongs only to payment or bypass of the displayed
typed conversion objects.

## 5. Revised local frontier

### Corollary PP3bas -- PROVED

For the complete second-host current row, neither raw host feasibility nor
internal coordinate supply remains open.

The next local frontier is the finite family of typed paid endpoints produced
by dense current support, principally:

1. arc- and path-petal banks;
2. weighted two-resource choice grids;
3. fixed-cell and partner-fan structures;
4. terminal insertion pencils and fixed cores; and
5. any downstream conditional host explicitly generated by those typed
   theorems.

The dense source-support row remains the separate fixed-template/paired-switch
frontier.  The global prime-minus-one seed theorem also remains separate.

The no-three-in-line conjecture remains unproved.
