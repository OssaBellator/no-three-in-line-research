# Fixed-column shell source-type obstruction

`docs/607` proves parity closure for compounds of the explicit `docs/517`
controls.  Earlier shell chapters introduce parametric targets, upward
quantization, and chamber stability.  Those operations may change coefficients
or demands, but they retain the same source-action columns.  Therefore they
cannot create the missing odd-sum action either.

The recorded action columns are

```text
v1=(1,0,1), v2=(1,1,0), v3=(0,1,1).
```

## 1. Fixed-column lattice invariance

### Theorem PP3cvf -- PROVED / TARGET AND COEFFICIENT OPERATIONS PRESERVE THE SOURCE LATTICE

Consider any shell procedure that keeps the action-column matrix fixed and only

- changes the cycle-demand vector;
- optimizes nonnegative action coefficients;
- rounds those coefficients upward to integers; or
- moves between dual chambers.

Every integer source schedule remains in the lattice generated by the fixed
action columns.

#### Proof

An integer source schedule has cycle vector `Az`, where the columns of `A` are
the source actions and `z` is an integer coefficient vector.  Changing the
right-hand side, objective, active dual vertex, or the rule used to select and
round `z` does not change `A`.  Hence every realized vector remains in
`A Z^E`. ∎

## 2. Application to the shell chain

### Theorem PP3cvg -- PROVED / DOCS 499, 505, AND 511 ADD NO ODD COLUMN

The multiparametric chamber walk of `docs/499`, coefficient ceiling quantization
of `docs/505`, and chamber-preserving target quantization of `docs/511` preserve
the recorded three-column source lattice.  Their integer outputs all have even
coordinate sum.

#### Proof

Each cited chapter explicitly formulates a fixed-column LP and modifies only the
target, objective regime, or coefficient denominator.  The checker audits one
thousand bounded integer column combinations and coefficient quantizations
through denominator twenty.  Every output has even coordinate sum. ∎

## 3. Exact source-type boundary

### Theorem PP3cvh -- PROVED / EXTENDED ODD-COSET ABSENCE

The integer lattice generated by the shell source columns is exactly

```text
{(a,b,c) in Z^3 : a+b+c is even}.
```

Consequently no operation in the recorded shell chain through `docs/517`,
including the parametric and quantized mechanisms above, realizes an odd-sum
cycle action.

#### Proof

The inverse coefficient formula is

```text
x1=(a-b+c)/2,
x2=(a+b-c)/2,
x3=(-a+b+c)/2.
```

It is integral exactly when `a+b+c` is even.  `PP3cvf--PP3cvg` show that none of
the derived shell operations changes the generating columns. ∎

## 4. Prime-patching consequence

The odd-coset shell action cannot be recovered by re-optimizing, quantizing, or
moving between chambers.  It must come from a genuinely new clean-macro source
operation with a new incidence column.
