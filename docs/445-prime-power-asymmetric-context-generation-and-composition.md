# Asymmetric context generation and contraction composition

This chapter records CMR2864--CMR2875. CMR2852--CMR2863 identify the exact
asymmetric host produced by one forced labelled triple. The present chapter
turns that host type into a canonical generated context and proves that further
deleted/required restrictions and forced-set contractions remain inside the
same class.

## CMR2864 — canonical asymmetric context

Fix an ambient integer grid `[n] x [n]`. For each labelled layer
`lambda in {0,1}`, choose canonical surviving coordinate domains

\[
R_\lambda\subseteq[n],
\qquad
K_\lambda\subseteq[n],
\qquad
|R_\lambda|=|K_\lambda|.
\]

The two matching sizes may differ across layers. Let `D` be a canonical deleted
edge set contained in the layer boards `R_lambda x K_lambda`, and let `P` be a
compatible required partial matching contained in those boards, with

\[
D\cap P=\varnothing.
\]

The tuple

\[
(n;R_0,K_0,R_1,K_1;D,P)
\]

is the canonical asymmetric context.

## CMR2865 — exact asymmetric feasible family

Define the feasible family to consist of pairs `(M0,M1)` such that:

1. `M_lambda` is a perfect matching from `R_lambda` to `K_lambda`;
2. the two labelled matchings have no common physical cell;
3. every edge of `D` is avoided; and
4. every edge of `P` is present.

The permutation generator over each layer domain produces exactly this family
and produces no duplicates.

### Proof

A permutation of `K_lambda` indexed by the canonical order of `R_lambda` is
exactly a perfect matching between those domains. Filtering by the literal
mask, required-set and physical-disjointness predicates gives both inclusions.
The two layer permutations reconstruct every generated state uniquely. ∎

## CMR2866 — exact triple universe and canonical anchor

The exact realizable collinear-triple universe is generated by inspecting every
three-edge subset of every feasible asymmetric state in the original grid
coordinates. For a nonempty family, the lexicographically least state is the
canonical asymmetric anchor.

No residual family, triple universe or anchor is externally supplied.

## CMR2867 — asymmetric empty/clean/dirty dispatch

Exactly one of the following occurs:

```text
asymmetric feasible family empty
  -> infeasible asymmetric-context terminal

least feasible state has no realizable triple
  -> clean asymmetric-anchor terminal

least feasible state has at least one realizable triple
  -> choose its least triple as canonical target
```

This closes canonical anchor and target generation on the enlarged host class.
It does not yet classify every dirty-anchor alternative.

## CMR2868 — exact asymmetric deletion extension

For an unclassified edge `f` in its layer domain,

\[
\boxed{
\mathcal F_{\rm asym}(D\cup\{f\},P)
=
\{S\in\mathcal F_{\rm asym}(D,P):f\notin S\}.
}
\]

The child triple universe is contained in the parent universe.

### Proof

Both families impose the same layer domains, required edges and physical-cell
constraint; the child imposes exactly one additional omitted edge. Every child
state is a parent state, giving triple-universe monotonicity. ∎

## CMR2869 — exact asymmetric required extension

If `P union {f}` is compatible, then

\[
\boxed{
\mathcal F_{\rm asym}(D,P\cup\{f\})
=
\{S\in\mathcal F_{\rm asym}(D,P):f\in S\}.
}
\]

Again the child triple universe is contained in the parent universe.

Thus first-missing side branches remain literal deleted/required context
extensions after the first contraction.

## CMR2870 — arbitrary forced-set contraction

Let `C` be any nonempty compatible subset of `P`. Remove from each layer domain
the rows and columns occupied by the edges of `C`. Restrict inherited deleted
edges to the surviving boards, remove `C` from the required set, and add every
opposite-layer blocker induced by a prescribed physical cell.

The resulting data form another canonical asymmetric context. Restriction and
adjoining give inverse bijections

\[
\boxed{
S\mapsto S\setminus C,
\qquad
S'\mapsto S'\cup C.
}
\]

The state cardinality drops by exactly `|C|`.

CMR2856 is the three-edge square-parent special case.

## CMR2871 — exact blocker and context transport

For each `(lambda,r,c) in C`, the only new opposite-layer deletion is

\[
(1-\lambda,r,c)
\]

when that coordinate remains in the opposite layer domain. Together with the
surviving inherited deleted edges, these blockers are the exact child mask.
The child required set is exactly `P minus C`.

No blocker at a removed row or column is retained, and no other physical cell is
forbidden merely because `C` was fixed.

## CMR2872 — exact forced-set triple transport

Let `U_parent` and `U_child` be the exact realizable triple universes in original
coordinates. Then

\[
\boxed{
\mathcal U_{\rm child}
=
\{T\in\mathcal U_{\rm parent}:T\cap C=\varnothing\}.
}
\]

This remains exact for forced sets of arbitrary cardinality, not only one
triple.

## CMR2873 — contraction composition

Let `C1` and `C2` be disjoint compatible forced sets contained in `P`. Contract
`C1` and then contract `C2` in the generated child. The resulting:

- row domains;
- column domains;
- deleted mask;
- required set;
- feasible family; and
- exact triple universe

are identical to those obtained by directly contracting `C1 union C2`.

### Proof

Rows and columns removed by successive set subtraction equal those removed by
the union. An inherited deleted edge survives precisely when its endpoint
coordinates survive both contractions. A blocker induced by either forced set
survives precisely when its coordinate remains after the union contraction.
The final required set is `P minus (C1 union C2)`. Applying the restriction map
twice is the same as deleting the union, and CMR2872 gives the same identity for
triple universes. ∎

Thus repeated conditioned contractions do not create a new local host type.
