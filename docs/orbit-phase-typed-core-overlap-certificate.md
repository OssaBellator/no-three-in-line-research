# Orbit-phase typed irreducible-core overlap

This note continues the canonical typed residual/edit-core result on the same complete finite payment network. It identifies the exact shared-source competition that the remaining physical argument must exclude or pay.

## Contract

For a typed terminal set `S`, let `d(S)` be total residual/edit demand, `F(S)` the maximum shared-source flow with only `S` enabled, and `Delta(S)=d(S)-F(S)`. Retain every residual or edit type, unit-sensitive physical address, source class, capacity and compatibility edge.

Let `C` be the canonical minimum-cardinality deficient typed core and put `delta=Delta(C)>0`. Every proper subset of `C` is fully payable.

## OP4dz--OP4ed

1. Every nonempty proper `A subset C` satisfies `F(A)=d(A)`.
2. Every nontrivial partition `C=A disjoint_union B` has exact competition `Omega(A,B)=F(A)+F(B)-F(C)=delta`.
3. If `C` contains both residual and edit addresses, the residual-versus-edit split is a canonical typed witness of overlap `delta`. If it is type-homogeneous and non-singleton, use the least balanced complete-address split. A singleton is a direct local typed shortage.
4. Any unit-sensitive physical decomposition producing additive payment across one retained split, or merely an overlap upper bound below `delta`, excludes the core.
5. Suppressed unit fields, merged residual/edit types, omitted compatibility, changed quotient states or independent reuse of shared source capacity is a reset rather than a paid core.

## Consequence

A remaining OP obstruction is either one direct typed shortage or two separately payable residual/edit families whose source optima overlap by the whole deficit. The next physical step is to separate one canonical split, bound its overlap below `delta`, or charge that exact overlap to a named source or edit account.

## Scope

This theorem is conditional on the complete fixed typed network and exact subset max-flow values. It does not prove OP5 or the no-three-in-line conjecture.
