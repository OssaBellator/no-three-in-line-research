# Acyclic dependency audit for fixed-infrastructure restart closure

The restart termination theorem PP3avj--PP3avk is useful only if its paid-repair and
support-conversion inputs do not themselves invoke restart termination.  This chapter
records a topological proof order for the focused slab-optimal chain.

The audit separates five layers:

1. fixed slab geometry and completion energy;
2. fixed-attempt numerical allocation;
3. local support and resource conversion;
4. pool-compatible restart and activation clearing; and
5. integer termination.

No theorem in layers one through four uses layer five.

## 1. Geometry and completion-energy base

Let `G_0` consist of the following inputs.

1. slab pool supply and scale optimization PP3ga--PP3gu;
2. patch-only cross-macro energy PP3he;
3. ordinary two-slot source-anchor energy PP3hg--PP3hk;
4. controller-aware candidate domains PP3hm--PP3ho; and
5. random two-sided ownership and local Ore allocation PP3nb--PP3nd.

### Proposition PP3awc -- PROVED

Every theorem in `G_0` is stated for one fixed saturated source or uniformly for all
saturated sources.  None uses a source-repair process, a dynamic restart potential, or
PP3avj--PP3avk.

#### Proof

The slab and patch-only results are coordinate-label statements.  PP3hg--PP3hk use
only saturation.  PP3hm--PP3ho define one-attempt controller-aware domains.  The
random two-sided theorem is a finite graph allocation statement. ∎

## 2. Fixed-attempt failure conversion

Let `G_1` contain:

1. blocker and anchor density conversion PP3akq--PP3alt;
2. score-mass conversion PP3alu--PP3alz; and
3. the fixed-attempt completion-or-repair theorem PP3auq--PP3auw.

### Proposition PP3awd -- PROVED

The extraction part of every theorem in `G_1` depends only on `G_0` and on static
source-incidence decompositions.  It produces a canonical marked star, bank,
matching, anchor structure, or insertion structure before any restart theorem is
used.

#### Proof

The conversion arguments are counting, star-versus-matching, and resource-refinement
statements on the current failed allocation table.  PP3auu invokes them only after the
one-attempt Ore dichotomy. ∎

Direct payment of the extracted structure belongs to the next layer, but extraction
itself is restart-free.

## 3. Local support and direct payment

Let `G_2` contain the complete support and canonical conversion results through
PP3aui, in particular:

1. positive-support localization PP3ama--PP3amy;
2. fixed-core and terminal-pencil closure PP3amz--PP3aoc;

4. bounded and critical marked hosts PP3aqh--PP3aqt and PP3arp--PP3ask;
5. layerwise cancellation PP3asl--PP3asz; and
6. direct payment of credited marked sets PP3auc--PP3aui.

### Proposition PP3awe -- PROVED

No theorem in `G_2` invokes fixed-attempt restart termination PP3avj--PP3avk.

Their only iterative mechanisms are:

1. finite support localization;
2. bounded marked cancellation;
3. nested candidate deletion; and
4. direct nonpositive or negative potential identities inside one repair package.

#### Proof

All cited results precede `docs/252` and are formulated for one current source,
one marked package, or one nested puncture history.  Their conclusions do not assume
that a later macro allocation attempt succeeds. ∎

Thus `G_2` may safely be used to pay the structures extracted by `G_1`.

## 4. Pool-compatible refinement is postprocessing

A canonical credited marked set may meet many permanent matching blocks.  PP3avc
partitions it into

```text
D_i=D cap E_i,
D_*=D cap E_*,
D_Q=D cap Q.
```

### Proposition PP3awf -- PROVED

Replacing one unrestricted direct marked cycle from `G_2` by the sequential
pool-compatible block cycles of PP3avc does not alter the preceding extraction or
resource-refinement proof.

It changes only the final host realization, and preserves:

1. total marked credit;
2. complete removal of cross-block incidences by first-deletion assignment;
3. the square helper bound `sum_j |D_j|^2<=|D|^2`; and
4. the canonical support type in every block.

#### Proof

Extraction determines a current marked source set and designated incidence list.
Block partition is performed afterwards.  PP3asn and PP3aue assign each incidence to
the first block deleting one of its marked endpoints, while PP3avc supplies the helper
bound.  No extraction lemma uses the eventual cyclic ordering. ∎

Therefore pool compatibility introduces no backward dependency.

## 5. Activation clearing uses only current support conversion

The dense branch of PP3avy and PP3awa invokes `G_2` after target-line constraints have
been pruned deterministically by PP3avv--PP3avx.

### Proposition PP3awg -- PROVED

Activation clearing has the following acyclic alternatives.

1. The target-clean current support table is sparse, so a zero-insertion clearing
   cycle exists.
2. The current support table is dense, so `G_2` produces and directly pays a current
   credited structure.
3. The paid structure moves the original marked repair set and spends its original
   allocation-failure credit.

None of these alternatives invokes PP3avj--PP3avk.

#### Proof

Target-line avoidance is deterministic domain pruning.  The remaining dense support
is precisely a current source or current potential event of a type in `G_2`.  Direct
payment is PP3auc--PP3aui with the pool-compatible postprocessing PP3awf. ∎

This discharges the only possible forward edge in PP3avd.

## 6. Topological proof order

### Theorem PP3awh -- PROVED

The fixed-infrastructure slab chain has the topological order

```text
G_0
 -> G_1 extraction
 -> G_2 local conversion and direct payment
 -> PP3aux--PP3awb restart/activation realization
 -> PP3avj--PP3avk integer termination.
```

Every arrow points from an earlier layer to a later layer.  In particular, the proof
of strict progress after a failed attempt does not assume termination of repeated
attempts.

#### Proof

Combine PP3awc--PP3awg. ∎
