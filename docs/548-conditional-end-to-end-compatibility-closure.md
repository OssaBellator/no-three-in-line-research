# Conditional end-to-end compatibility closure

This chapter composes `docs/543--547` into one synthetic end-to-end certificate.
It is intentionally a conditional reduction.  The actual all-`n` no-three-in-line

## 1. Typed interface composition

### Theorem PP3cns -- PROVED / SIX-FRONTIER INTERFACE COMPOSITION

Assume the following certificates are supplied for a side length `N`:

1. a boundary marker word in the demanded phase;
2. a legal Hall/threshold/shell product word returning all finite states;
3. a prefix-code object satisfying its declared risk row;
4. integer block counts satisfying the rational target rows;
5. an interaction choice satisfying its declared support row;
6. an additive loss bound below the global margin.

If every produced state and resource matches the input type of the next
certificate, their concatenation is a valid abstract compatibility certificate.

#### Proof

Each interface is a predicate on typed inputs and outputs.  Matching adjacent
types permits ordinary composition.  Additivity of the declared losses and the
strict final inequality give the global resource condition. ∎

## 2. Synthetic eventual closure

### Theorem PP3cnt -- PROVED / ABSTRACT ALL-LENGTH FIXTURE

In the stored abstract model, every `N>=361` has a compatibility certificate:

- phase `t(N)=N mod 3` is realized by `4a+7b=N` with `b congruent t(N) mod 3`;
- the 24-state synchronizer uses two copies of a shortest return word, giving
  Hall contraction `9/65536<1/100`;
- the six target block proportions are integerized by largest remainders;
- the base loss is `7/30`, and the implementation penalty is less than `6/N`;
- therefore the total is less than `1/4` for every `N>=361`;
- all period data factor through the 24-state residue table.

#### Proof

The marker statement follows from `PP3cni`; the synchronizer from `PP3cno`; the
integerization from `PP3cnr`; and the loss inequality from

```text
7/30+6/N<7/30+1/60=1/4.
```

The combined residue assertion is `PP3cnd`. ∎

## 3. Honest geometric gap ledger

### Theorem PP3cnu -- PROVED / CONDITIONAL GLOBAL-CLOSURE REDUCTION

To turn `PP3cnt` into a prime-patching theorem, it is sufficient to prove six
realization statements with the displayed constants:

1. the actual boundary defects admit the phase-locked marker catalogue;
2. the actual local syndrome gadgets induce the two certified Hall transitions;
3. every threshold inequality is controlled by the declared common-box row;
4. a legal prefix object exists with the required support and risk profile;
5. the true coupled shell incidence system admits the declared pooled phase row;
6. the interaction optimizer and all cross-terms fit the additive ledger without
   hidden losses.

If any attempted geometric composition fails, at least one of these six typed
realization statements fails.

#### Proof

Under all six statements, `PP3cns` applies and `PP3cnt` supplies the numerical
certificate.  Conversely, the abstract composition uses no undeclared input; a
failure of geometric instantiation must therefore occur when matching one of the
six abstract rows to its claimed geometric realization. ∎
