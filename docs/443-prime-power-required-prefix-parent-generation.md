# Required-prefix parent generation

This chapter records CMR2840--CMR2851. It extends the canonical masked-host
parent from a deleted-edge mask to a deleted/required context and proves that
every first-missing prescription child is generated exactly by such a context.

The executable checker is:

```text
scripts/check_prime_power_required_prefix_parent_generation.py
```

## CMR2840 — compatible required context

For side \(n\), retain the labelled host

\[
H_n=\{0,1\}\times[n]\times[n].
\]

Let \(D\subseteq H_n\) be a deleted-edge mask and let \(P\subseteq H_n\) be a
required-edge set. The context \((n,D,P)\) is canonical when:

1. \(D\cap P=\varnothing\);
2. no two edges of \(P\) repeat a row or column in one layer; and
3. no two edges of \(P\) occupy the same physical cell.

These are exactly the local compatibility conditions inherited from a labelled
saturated two-layer state. They do not by themselves guarantee a completion.

## CMR2841 — exact contextual feasible family

Define

\[
\mathcal F(n,D;P)
=
\{S\in\mathcal F(n,D):P\subseteq S\}.
\]

Then the permutation generator with the simultaneous tests

```text
S cap D = empty
P subset S
```

produces exactly \(\mathcal F(n,D;P)\), with no duplicates.

### Proof

CMR2829 gives a unique permutation pair for every saturated labelled state.
Filtering the generated masked family by the literal containment predicate
\(P\subseteq S\) proves both inclusions and preserves injectivity. ∎

An empty contextual family is an exact infeasible-context terminal.

## CMR2842 — contextual triple universe and anchor

Define

\[
\mathcal U(n,D;P)
=
\bigcup_{S\in\mathcal F(n,D;P)}
\{T\subseteq S:|T|=3,\ T\text{ is physically collinear}\}.
\]

The checker reconstructs this universe from the generated contextual family and,
when the family is nonempty, chooses its lexicographically least state as the
canonical contextual anchor.

Thus the required context does not introduce a supplied family, triple universe
or anchor.

## CMR2843 — exact deleted-edge extension

For an edge \(f\notin D\cup P\),

\[
\boxed{
\mathcal F(n,D\cup\{f\};P)
=
\{S\in\mathcal F(n,D;P):f\notin S\}.
}
\]

### Proof

Both sides are exactly the saturated states which contain every edge of \(P\)
and avoid every edge of \(D\cup\{f\}\). ∎

This is the literal contextual realization of a single-edge deletion child.

## CMR2844 — exact required-edge extension

If \(f\notin D\) and \(P\cup\{f\}\) is compatible, then

\[
\boxed{
\mathcal F(n,D;P\cup\{f\})
=
\{S\in\mathcal F(n,D;P):f\in S\}.
}
\]

### Proof

Both sides impose the same deleted edges and the same required edges. ∎

Thus a positive branch condition is generated by extending the required set,
not by supplying an arbitrary subfamily.

## CMR2845 — contextual triple-universe monotonicity

Every deleted-edge or required-edge extension restricts the parent family.
Therefore

\[
\mathcal U(n,D\cup\{f\};P)
\subseteq
\mathcal U(n,D;P)
\]

and

\[
\mathcal U(n,D;P\cup\{f\})
\subseteq
\mathcal U(n,D;P).
\]

Deletion and conditioning cannot create a labelled triple which was not
realizable in the parent context.

## CMR2846 — canonical first-missing child contexts

Let \(C=(f_0,f_1,f_2)\) be a canonically ordered labelled prescription contained
in a rejected state \(Q\in\mathcal F(n,D;P)\). For \(i=0,1,2\), define

\[
P_i=P\cup\{f_0,\ldots,f_{i-1}\},
\qquad
D_i=D\cup\{f_i\}.
\]

Define the conditioned context

\[
P_3=P\cup C,
\qquad
D_3=D.
\]

If \(f_i\in P\), the formal branch \((D_i,P_i)\) has a required/deleted
contradiction and is canonically empty. No arbitrary empty-child convention is
needed.

## CMR2847 — exact branch realization

For \(i=0,1,2\),

\[
\boxed{
\mathcal F(n,D_i;P_i)
=
\{S\in\mathcal F(n,D;P):
 f_0,\ldots,f_{i-1}\in S,\ f_i\notin S\}.
}
\]

For the conditioned branch,

\[
\boxed{
\mathcal F(n,D_3;P_3)
=
\{S\in\mathcal F(n,D;P):C\subseteq S\}.
}
\]

### Proof

Apply CMR2843 to the omitted edge and CMR2844 successively to the required
prefix. The contradiction case is empty because a state cannot both contain and
omit the same labelled edge. ∎

Hence every branch in the CMR2794 first-missing rule is generated from a finite
context \((n,D,P)\).

## CMR2848 — disjoint exhaustive contextual partition

Every state in \(\mathcal F(n,D;P)\) has one unique first missing index in
\(C\), with index three meaning that all three edges occur. Therefore

\[
\boxed{
\mathcal F(n,D;P)
=
\dot\bigcup_{i=0}^{3}\mathcal F(n,D_i;P_i).
}
\]

The rejected state \(Q\) occurs only in branch three.

This is stronger than the nondisjoint CMR862 union and matches the canonical
first-missing partition used by CMR2794--CMR2805.

## CMR2849 — exact conditioned set contraction

Inside branch three every state contains \(C\). The map

\[
S\longmapsto S\setminus C
\]

is injective and lowers labelled state cardinality by three.

The checker records this exact set-family contraction but deliberately does not
claim that the residual family is already a standard smaller masked host. That
requires a separate theorem specifying the row, column, physical-cell and
opposite-layer relabelling induced by a genuine contraction.
