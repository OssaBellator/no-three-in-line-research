# Complete second-host call-matrix audit

PP3azs--PP3azz replace rank-by-rank payment of a first endpoint package by one
complete blockwise second host.  The only task left by PP3azz is to check that
all failure alternatives of that host are invoked with the hypotheses actually
supplied at the call site.

This chapter performs that audit.  It closes the **assembly mismatch**, not the
named geometric conversion interfaces themselves.  In particular, a row ending
at a conditional Hall, alternating, non-superregular, distinguished-endpoint,
or role-host interface remains conditional exactly where that earlier theorem
is conditional.

Throughout, the current restart potential is

```text
Theta_E^+=Xi_cell+Lambda_E+Xi_old.
```

Let a source-valid first package insert the finite set `D`, and partition `D`
by post-trade permutation layer and permanent matching block:

```text
D=D_1 dot-union ... dot-union D_k,
r_j=|D_j|,
s=sum_j r_j.
```

The first package has complete current removal credit `R_1^+>0` and first-step
insertion multiplicity `I_1^+` in `Theta_E^+`.

## 1. Universal data supplied to every second-host row

### Proposition PP3baa -- PROVED

Every nonempty block `D_j` reaches PP3azu with the following data.

1. `1<=r_j<=W` marked endpoint roles in one current permutation layer and one
   permanent matching block.
2. `Theta(max(r_j^2,1))` unreserved helpers in that block.
3. At most `O(r_j)` selected-controller punctures and at most `O(r_j)` forbidden
   helper values in each role domain.
4. A complete support hypergraph of rank at most three containing every positive
   source-validity, `Xi_cell`, `Xi_old`, active-anchor, and controller-activation
   event for the proposed second cycle.
5. Fixed coordinate sets, numerical labels, controller rectangles, and
   candidate-cell universes.

#### Proof

The layer/block partition and quadratic helper supply are PP3azu and PP3azv.
Selected-controller puncturing, endpoint reservations, and complete support rank
are part of the complete endpoint normal form and PP3ayd.  Their role-domain
loss is linear in the marked size, so the buffered role-domain host PP3awo
applies after trimming the block to a quadratic subreservoir.  Fixed
infrastructure is preserved blockwise by PP3avc and PP3azk. ∎

The audit therefore never calls a square-root host with a super-square-root
marked set or with an unrecorded superlinear domain loss.

## 3. Independent-row payment

### Theorem PP3bab -- PROVED

If every nonempty block receives the independent zero-current-cost cycle of
PP3azu item 1, then

```text
Theta_(E_final)^+(S_final)-Theta_(E_0)^+(S_0)
<=-R_1^+.
```

#### Proof

Every first-step new incidence meets `D` by PP3azs.  Deleting the complete set
`D` therefore removes at least `I_1^+` multiplicity by PP3azt.  The independent
second cycles create zero replacement incidence in every component of
`Theta_E^+`.  Adding the first and later changes gives

```text
I_1^+-R_1^+-I_1^+<=-R_1^+,
```

which is PP3azw. ∎

This row does not require any unary/binary decomposition of the first insertion
table.

## 4. Dense current-support row

### Theorem PP3bac -- PROVED / CONDITIONAL NAMED CURRENT CONVERSION INTERFACES

Suppose one second-host block fails through dense current support.  Then after
finite canonical-type refinement and, when necessary, hereditary truncation,
there is a current credited structure with marked size `h` satisfying

```text
1<=h<=W.
```

Its call site supplies:

1. one current source layer and explicit permanent-block membership;
2. `Theta(max(h^2,1))` helpers after PP3awn;
3. `O(h)` controller punctures and role-domain losses;
4. rank-at-most-three complete current support;
5. actual marked source endpoints carrying every designated credit unit with
   multiplicity.

Consequently the structure enters the scale-uniform permanent-block payment
chain PP3axa--PP3axh and either strictly decreases `Theta_E^+` or ends at one of
its already named current endpoint-host interfaces.

The original first-package credit is not double counted.

#### Proof

PP3awo turns failure of the independent assignment into an `Omega(r_j)`
canonical support object.  PP3axe truncates an oversized object without losing
its typed credit, while `r_j<=W` handles the remaining scale.  PP3axb--PP3axf
attach every cell-shadow or active-anchor incidence to an actual current source
endpoint and count it at first deletion.  Unary old-grid support is current
`Xi_old` credit by PP3aye.  The direct-payment alternatives are PP3axg and the
current conversion chain through PP3aui.  These use the newly extracted current
credit; `R_1^+` remains reserved unless its own incidence has already vanished
favourably. ∎

## 5. Dense source-support row

### Theorem PP3bad -- PROVED / CONDITIONAL NAMED CURRENT AND ENDPOINT-HOST INTERFACES

Suppose one second-host block fails through dense source support.  Then exactly
one of the following occurs.

1. Unary retained-pair support is current `Xi_old` credit and enters PP3bac.
2. A fixed-template secant-clean completion gives lexicographic progress.
3. A complete secant cover yields a fixed-centre paired-switch star or a
   target-order resource-disjoint paired-switch bank.
4. The paired bank has a source-valid joint state and retains the first-package
   credit until that state is installed.
5. Its residual current weight enters PP3bac.
6. A conditional Hall, alternating, non-superregular, distinguished-endpoint,
   or locally impossible role-host interface is displayed explicitly.
7. A robust final-state branch installs the patch.

No outcome is a new untyped source-host family.

#### Proof

Item 1 is PP3aye.  Items 2--3 are the fixed-template descent and secant-cover
extraction PP3ayg--PP3azr.  The paired switches preserve each permanent block,
have a four-state alphabet, and retain support rank at most three by
PP3azk--PP3azn.  Chromatic thinning removes the two-inserted-cell source mass by
PP3azf.  PP3azg--PP3azh then give items 4--7 and prove that the source-host route
is acyclic. ∎

## 6. Explicit-host row

### Proposition PP3bae -- PROVED

Every explicit failure named in PP3azu item 4 has all parameters needed to be a
terminal call-matrix row:

1. the used endpoint resources and conditioned cells are explicit;
2. the marked size is at most `W`;
3. the current potential is `Theta_E^+`;
4. permanent blocks and source layers are recorded;
5. selected-controller punctures and role losses are `O(r_j)`;
6. no original or newly extracted credit is declared spent merely because the
   interface failed.

#### Proof

The complete support table is built after the layer/block partition, endpoint
reservation, and selected-controller puncturing.  A Hall rectangle records its
conditioned resource deletion; an alternating or non-superregular branch records
its residual endpoint host; a distinguished-endpoint branch records the fixed
cell or resource; and role-host failure records the missing role domain.  These
are outputs of the same PP3awo invocation, so the scale and domain bounds of
PP3baa remain attached. ∎

This proposition is bookkeeping.  It does not prove the terminal interfaces.

## 7. Global helper accounting

### Proposition PP3baf -- PROVED

The total quadratic helper volume required by all independent second-host blocks
satisfies

```text
sum_j Theta(r_j^2)=O(s^2).
```

Sequential block processing does not create hidden cross-block helper depletion.

#### Proof

The elementary inequality

```text
sum_j r_j^2<=(sum_j r_j)^2=s^2
```

is PP3azv.  Each cycle uses helpers only in its permanent block.  Paired secant
switches use a bounded number of fillers in each participating block and preserve
both blocks internally.  Previously processed blocks therefore do not consume
helpers from an unprocessed block. ∎

## 8. Complete second-host endpoint

### Theorem PP3bag -- PROVED / CONDITIONAL FINITE NAMED INTERFACE SET

For every source-valid first endpoint package, the complete blockwise second host
has exactly one of the following outcomes.

1. Complete insertion cancellation gives strict `Theta_E^+` payment.
2. A newly credited current structure gives strict payment.
3. A source-valid composite state preserves and then spends the original credit.
4. A robust final-state branch installs the patch.
5. One explicitly named current or endpoint-host interface fails.

There is no sixth outcome consisting of an unclassified insertion table,
unbounded cumulative source-host family, missing helper scale, lost designated
credit, or cross-pool controller mismatch.

#### Proof

Apply PP3baa blockwise.  Row A is PP3bab, row B is PP3bac, row C is PP3bad,
row D is PP3bae, and robust completion is row E.  PP3baf validates the aggregate
helper budget.  The rows are exhaustive because they are exactly the alternatives
of PP3azu and PP3azg. ∎

## 9. Revised local and global frontiers

### Corollary PP3bah -- PROVED

The theorem-by-theorem call-matrix task stated in PP3axp, PP3azj, and PP3azz is
complete.  The master exact-width theorem may now cite the finite named interface
set rather than an open-ended post-first-package audit.

Two logically different frontiers remain.

1. **Local conditional interfaces:** the named current, Hall, alternating,
   non-superregular, distinguished-endpoint, and role-host conversion leaves must
   be proved or bypassed in their own hypotheses.
2. **Global seed theorem:** saturated no-three configurations on `[p-1]^2` for
   every sufficiently large prime are still assumed.

The no-three-in-line conjecture remains unproved.
