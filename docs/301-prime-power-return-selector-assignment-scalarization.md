# The return-selector block is one weighted assignment cost

CMR1574--CMR1581 replace undefined return churn by an exact exchange-pair
kernel.  CMR1558--CMR1565 replace every subunit paid-pair selector by a bounded
row into repeated return.  The remaining two-row condition is

\[
\alpha+T\beta<1.
\]

It is wasteful to estimate `alpha` and `beta` separately.  Both are generated by
the same response matching and therefore share one doubly stochastic matching
marginal.  Their scalarized combination is exactly one owner-weighted assignment
cost.  A single rational assignment dual can certify the whole return-selector
block, and incompatible worst matchings for the two coordinates are never added.

Fix a finite bipartite response host `G` with source set `L`, target set `R`, and
one old selected perfect matching `M`.  Let `nu` be a rational probability law
on a finite nonempty family

\[
\mathcal B\subseteq\operatorname{PM}(G).
\]

For `Q in mathcal B`, let `E^+(Q)=Q\setminus M` and use the absolute
last-entering order.  For an entering edge `a in E^+(Q)`, write

\[
k_{\rm ret}(a,Q),
\qquad
k_{\rm sel}(a,Q)
\]

for the numbers of recreated recurrent return credits and recreated subunit
selector credits whose canonical owner is `a`.  Put both values equal to zero
when `a notin E^+(Q)`.

## 1. Exact response-edge marginal

For an allowed edge `a`, define

\[
p(a)=\Pr_{Q\sim\nu}(a\in Q).
\]

### Theorem CMR1582 -- PROVED

The matrix `p` is doubly stochastic on the allowed host:

\[
\boxed{
\sum_{a\ni x}p(a)=1
\quad(x\in L),
\qquad
\sum_{a\ni y}p(a)=1
\quad(y\in R).
}
\]

It is a rational point of the perfect-matching polytope of `G`.

### Proof

Every sampled response matching uses exactly one edge at every source and target
vertex.  Average these incidence identities under the rational law `nu`.
Rationality is immediate. ∎

## 2. Conditional owner loads

For `c in {ret,sel}` and `p(a)>0`, define

\[
g_c(a)=
\mathbb E_{Q\sim\nu}
\bigl[k_c(a,Q)\mid a\in Q\bigr].
\]

Set `g_c(a)=0` when `p(a)=0`.  Old unchanged edges have zero load because they
are not entering owners.

Let

\[
\alpha=
\mathbb E_{Q\sim\nu}
\sum_{a\in Q}k_{\rm ret}(a,Q),
\qquad
\beta=
\mathbb E_{Q\sim\nu}
\sum_{a\in Q}k_{\rm sel}(a,Q).
\]

### Theorem CMR1583 -- PROVED

The two return-kernel row sums have exact owner expansions

\[
\boxed{
\alpha=\sum_{a\in E(G)}p(a)g_{\rm ret}(a),
\qquad
\beta=\sum_{a\in E(G)}p(a)g_{\rm sel}(a).
}
\]

### Proof

Expand each expectation by entering owner, then condition on the event `a in Q`.
CMR1578 identifies the sum of owner loads with the exact returned-edge kernel
count, so no recreated credit is lost or counted twice. ∎

## 3. Scalarized return-selector identity

Fix a nonnegative selector-to-return cap `T`; in the CMR1564 application `T` is
an integer.  Put

\[
h_T(a)=g_{\rm ret}(a)+Tg_{\rm sel}(a).
\]

### Theorem CMR1584 -- PROVED

\[
\boxed{
\alpha+T\beta
=
\sum_{a\in E(G)}p(a)h_T(a).
}
\]

Thus the exact spectral scalar from CMR1562 is one edge-assignment expectation,
not the sum of two independently optimized rows.

### Proof

Multiply the second identity of CMR1583 by `T` and add it to the first. ∎

## 4. One assignment primal and dual

Define

\[
\mathcal A_T
=
\max_{Q\in\operatorname{PM}(G)}
\sum_{a\in Q}h_T(a).
\]

### Theorem CMR1585 -- PROVED

\[
\boxed{
\alpha+T\beta\le\mathcal A_T.
}
\]

Moreover

\[
\boxed{
\mathcal A_T
=
\min
\left\{
\sum_{x\in L}u_x+
\sum_{y\in R}v_y:
 u_x+v_y\ge h_T(x,y)
 \text{ on }E(G)
\right\}.
}
\]

The minimum has a rational optimizer whenever all `h_T(a)` are rational.

### Proof

By CMR1582, `p` lies in the bipartite perfect-matching polytope.  Its scalar
product with `h_T` is therefore at most the maximum over the integral vertices,
which are the perfect matchings of `G`.  The displayed minimum is the standard
assignment dual.  A rational linear program has a rational optimum. ∎

This shared optimization can be strictly smaller than

\[
\max_Q\sum_{a\in Q}g_{\rm ret}(a)
+
T\max_Q\sum_{a\in Q}g_{\rm sel}(a),
\]

because the two separate maxima may require incompatible response matchings.

## 5. Direct spectral certificate

### Theorem CMR1586 -- PROVED

Suppose there are rational potentials `u_x,v_y` satisfying

\[
 u_x+v_y\ge
 g_{\rm ret}(x,y)+Tg_{\rm sel}(x,y)
\]

on every allowed edge and

\[
\boxed{
\sum_xu_x+\sum_yv_y<1.
}
\]

Then

\[
\boxed{\alpha+T\beta<1,}
\]

and the recurrent return-selector block

\[
\begin{pmatrix}
\alpha&\beta\\
T&0
\end{pmatrix}
\]

has spectral radius below one.

### Proof

CMR1585 bounds `alpha+T beta` by the dual objective.  Apply the exact CMR1562
criterion. ∎

No separate estimates for `alpha` and `beta` are required.

## 6. Strict integer certificate

Assume all edge scores and dual variables have common denominator `D>0`.  Write

\[
H_T(x,y)=D h_T(x,y),
\qquad
U_x=Du_x,
\qquad
V_y=Dv_y.
\]

### Theorem CMR1587 -- PROVED

CMR1586 is certified by the finite strict integer system

\[
\boxed{
U_x+V_y\ge H_T(x,y)
\quad((x,y)\in E(G)),
}
\]

\[
\boxed{
\sum_xU_x+\sum_yV_y<D.
}
\]

Conversely every such integer system gives a rational spectral certificate after
division by `D`.

### Proof

Clear denominators in CMR1586. ∎

This is directly compatible with the integer Lyapunov format of CMR1270--CMR1277
and CMR1326--CMR1333.

## 7. Honest coarse exchange classes

Let

\[
\sigma(a)\in\mathcal S
\]

be any finite edge class retaining returned-edge/entering-owner exchange data,
for example alternating-cycle length, owner layer, residual rank, line-height,
token, prefix, carry, root/fixed-interface and thin-factor labels.  Suppose

\[
g_{\rm ret}(a)\le R_{\sigma(a)},
\qquad
 g_{\rm sel}(a)\le S_{\sigma(a)}.
\]

Put

\[
H_T(s)=R_s+TS_s.
\]

### Theorem CMR1588 -- PROVED

The scalarized return-selector row is bounded by the finite class-assignment
problem

\[
\boxed{
\alpha+T\beta
\le
\max_{Q\in\operatorname{PM}(G)}
\sum_{a\in Q}H_T(\sigma(a)).
}
\]

Any row/column potentials dominating these class scores give an honest rational
or integer upper-quotient certificate.

### Proof

Pointwise domination gives `h_T(a)<=H_T(sigma(a))`.  Apply CMR1585. ∎

In particular, the immediately checkable bounds

\[
\mathcal A_T
\le
\sum_{x\in L}
\max_{xy\in E(G)}h_T(x,y)
\]

and its target-column analogue are valid dual certificates.  Their minimum may
be used before solving the exact assignment problem.

## 8. Return-selector scalarization endpoint

### Corollary CMR1589 -- PROVED

For every rational response law and every subunit selector cap `T`:

1. the exact coupled spectral scalar is one owner-weighted assignment cost;
2. one shared primal/dual optimization replaces separate return and selector
   maxima;
3. a rational dual objective below one proves the complete two-row block
   subcritical;
4. denominator clearing gives a finite strict integer certificate;
5. all existing owner, rook, height, token, prefix and carry envelopes may be
   inserted as finite edge classes in that one assignment problem.

The return frontier is therefore no longer to estimate `alpha` and `beta`
independently.  It is to construct a host-uniform dual for the single combined
score

\[
 g_{\rm ret}+Tg_{\rm sel}.
\]

Critical selector hosts with `A_L>=1`, residual trace incidences, root/fixed-
interface rows and thin base rows remain separate.  No all-`n` theorem is
claimed.

versus separate maxima, rational dual certificates and integer clearing are
checked in
